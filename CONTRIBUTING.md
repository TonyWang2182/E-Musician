# Contributing

Start with the [build guide](docs/BUILD.md). Open an issue describing the problem or a pull request with a focused change.

For audio bugs, include the application version, audio device, driver, sample rate, buffer size, and steps to reproduce. For assistant bugs, include the task and visible error with credentials removed.

Keep project edits in the common command layer. Add a regression check when a bug affects saved state, recording, audio continuity, or command validation. Run the checks relevant to your change and include their results in the pull request.

Write code, comments, and documentation in English. User-created names, lyrics, paths, and prompts may use any language.

Contributions are provided under the project's AGPL-3.0-only license.
