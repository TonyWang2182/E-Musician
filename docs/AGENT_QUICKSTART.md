# Kimi 编曲助手 0.1

助手是一个本机网页窗口，和它启动的 E-musician 0.6.1 配合。网络请求在 Python 辅助进程执行；DAW 的音频线程保持原有实现。当前只连接启动器新开的 DAW，不控制另一个已经打开的窗口。

## 启动

本机快捷入口：`E:\MusicAgent&DAW\Start E-musician Agent.cmd`。源码工作树根目录也有 `Start-Agent.cmd`。它会打开 DAW 和默认浏览器中的助手，凭证已在本机加密配置。

通用命令（在本分支仓库根目录）：

```powershell
python scripts/run_agent.py --exe "E:/E-musician/build/bin/Release/E-musician.exe"
```

运行需要 Windows、Python 3.10+（本轮验证3.14）及已构建的 DAW；助手运行没有第三方 Python 包依赖。模型默认 `kimi-k2.6`，来源是本账号实际模型列表及官方参数说明。可在“模型设置”更换官方服务地址和模型，非密钥设置会保存到本机。

如需替换密钥，可在助手的模型设置填写，或运行 `python scripts/run_agent.py --configure-key` 使用隐藏输入。不要将密钥填入命令行参数、源码或 Git。Windows DPAPI 密文位于 `%LOCALAPPDATA%\E-musician\agent\moonshot.key`，绑定当前 Windows 用户。此前聊天中发出的凭证建议在平台轮换；不影响本地代码继续使用新凭证。

## 人工短测

1. 启动后，在**这次新开的 DAW**里打开一个测试工程，先保存副本。确认助手显示的工程名和轨道对应。
2. 输入“把速度改成100 BPM，并把钢琴轨音量设为-4 dB”。看方案中的具体目标和前后数值，点击应用；确认 DAW 跟着变化。点击“撤销这次修改”，两项应一起还原。
3. 在 DAW 选中一个已有音符的 MIDI 片段，输入“把选中的 MIDI 片段全部升高一个八度”。确认方案后应用，查看钢琴卷帘并播放试听，再撤销。音符数、时值和力度应保持。
4. 再生成一个方案，先不应用，回 DAW 手动改轨名，再点应用。应提示工程已变化，不应覆盖手工修改。重新提出要求即可。
5. 结束前在 DAW 保存，再点助手右下“关闭助手”；未保存时应明确阻止关闭，并在对话框内显示原因。只关闭网页不会结束 DAW，重新打开同一浏览器会话页面仍可连接。

录音、插件窗口和实际听感由用户测试；自动测试没有打开物理声卡。无需重做此前确认过的整套 DAW 录音回归。

## 可以做什么

- 查询工程结构、解释目前可见的轨道和 MIDI 数据。
- 设速度、改轨名、轨道音量/声像/静音/独奏。
- 新建音频/乐器/Bus轨，在**既有**乐器轨上新建空 MIDI 片段，移动已有片段。
- 对指定 MIDI 片段做移调、起音量化（含1/16384）、力度调整。默认整个片段；如需具体音符，必须使用明确ID，不能假装读取了钢琴卷帘的GUI多选。
- 同一方案作为一次原子 batch 提交，回读检查；后续尚无其他编辑时可一步撤销。

首版不生成音频、不听音频、不操作插件、录音、保存或删除文件；不提供自动保存/恢复。新轨/新片段的ID由DAW创建，须应用后在下一次要求里使用。单个方案最多16项动作、最多2000次音符处理；快照最多每轨64片段/全局256片段，超出时明确截断，不能暗中推断完整工程。

## 费用、数据和异常

每次要求最多4次模型请求，每次最多2048输出token；界面显示请求次数和服务返回的token计数，不推算未知价格。未使用自动付费重试。取消会阻止后续步骤，但已经发到模型服务的请求可能仍收费。

模型接收你的文字要求、近期对话、工程结构，以及按需读取的MIDI统计与少量音符示例。音频文件、插件预设和本机文件路径不会随本轮请求上传。模型不能使用shell或任意文件工具。完整音符在本地校验器中处理。

方案绑定工程ID、revision和对象ID；思考或确认期间工程变化会拒绝旧方案。连接超时可能意味着DAW已收到动作，因此助手停止后续命令，不自动重放；请到DAW查看实际状态。断线但DAW仍存活时不会强制关闭，请先在DAW保存并手动关闭。

运行审计在 `%LOCALAPPDATA%\E-musician\agent\audit.jsonl`，最多保留当前及上一份约5MiB元数据日志：任务/方案ID、命令摘要哈希、版本和结果；不保存完整对话、音符或模型思考内容。这不是工程恢复文件。开发证据见[本轮验证](verification/2026-10-29-kimi-agent/RESULTS.md)。
