# E-musician Agent 0.2 第一批

当前对应 DAW **0.7.0**：助手放在 DAW 内部侧栏，模型网络仍在独立 Python 进程运行。本批构建及自动验证已完成：CTest 5/5、Python 178 项、原生侧栏 23 项通过；真实 GPT-5-mini 和 Kimi-k2.6 均已在合成工程完成编辑、回读和撤销。详细证据见[本批验证结果](verification/2026-10-29-agent-sidebar/RESULTS.md)。实际界面、中文输入法与 ASIO 播放仍按下方人工检查确认；离屏原生测试使用合成 focusin 检查焦点桥和快捷键保护，不能代替真实点击与输入。

## 启动与收起

先保存并关闭现有 **0.6.1** 或其他旧版窗口，再双击本机快捷入口：`E:\MusicAgent&DAW\Start E-musician Agent.cmd`。启动后确认标题栏为 **0.7.0**；旧窗口未关时，单实例机制可能把请求交给旧版，导致看不到新侧栏。

工作树也可双击 `Start-Agent.cmd`；它经 `scripts/Start-Agent.ps1` 启动原生 DAW 的 `--agent` 模式。默认产物为 `build/sidebar/bin/Release/E-musician.exe`，不会覆盖原来的 0.6.1 构建。

DAW 工具栏点 **Agent**，或使用 **Ctrl+Shift+A**，打开/收起侧栏。聊天输入时也可用该快捷键收起；Escape 会先关闭展开的模型设置，否则收起侧栏。第一次打开才启动助手；收起保留草稿和任务，工程继续存在。保存工程和退出应用由 DAW 主窗口负责，侧栏没有“关闭 DAW”权限。

在本分支工作树根目录开发：

```powershell
python scripts/dev_agent.py build
python scripts/dev_agent.py test
python scripts/dev_agent.py run
```

默认 Release；需要时传 `--config Debug`。这些入口统一记录构建、测试和运行日志。需要 Windows、Python 3.10+、固定的原生依赖和 WebView2 Runtime；Python 助手本身不需要第三方运行时包。WebView2 SDK 由构建准备脚本固定版本和哈希，运行时缺失与模型配置失败分别处理。

旧命令 `python scripts/run_agent.py --exe PATH` 仍是兼容的独立浏览器/伴随进程入口，连接它自己启动的 DAW；日常使用新的原生侧栏入口。

## 先选范围，再提要求

默认范围是**当前选择**。例如先在钢琴卷帘选中两个音符，再输入“只把当前选中的音符升高两个半音”。助手应列出这两个音符的具体前后变化；点应用后才修改工程。一键撤销本次修改要求期间没有其他工程编辑。

侧栏读取实际的轨、片段、音符和时间区间，切到聊天输入时保留最后音乐选择。发送后若改变选区、轨名、音符或工程，旧方案会被拒绝，须重新生成。助手不会把空选区自动扩大成全工程。

修改全局速度或新建轨时，明确把范围切到**整个工程**，例如“把工程速度改为100 BPM”。这只是授权范围，仍需查看方案并点击应用。修改 BPM 不会自动拉伸音频。

每个待编辑 MIDI 片段必须完整读取，当前上限为 2000 个音符；单方案最多16项动作、2000次音符处理。超过上限会提示缩小目标，不默默截断。摘要未显示的选中片段会通过分页按 ID 补齐，读取期间工程版本变化则停止。当前 UI 只展示“当前选择/整个工程”；底层 clip 范围接口未作为第三个产品选项。

## 模型设置

已实现 **Kimi** 和 **OpenAI** 适配器；可在模型设置中切换服务、具体模型和对应凭证。Anthropic、Gemini、本地兼容服务明确标为未实现，不能使用。看到“已配置”只代表本机存在凭证，不等于模型权限或网络已验证；运行时不自动回退到另一厂商。

**当前交付机器已经加密配置两套密钥，无需重新提供或粘贴。** 本轮已实测的模型为 `kimi-k2.6` 和 `gpt-5-mini`。在顶部模型名处展开设置即可切换；其他模型、账户或机器仍需各自验证。

密钥按供应商加密保存于当前 Windows 用户的 DPAPI 文件：`%LOCALAPPDATA%\E-musician\agent\moonshot.key` / `openai.key`。模型偏好分别保存，切换不会覆盖另一服务的密钥。仅在日后更换密钥或配置其他机器时，也可以使用隐藏输入：

```powershell
python scripts/run_agent.py --provider kimi --configure-key
python scripts/run_agent.py --provider openai --configure-key
```

不要把密钥放进命令行参数、源码、工程或 Git。OpenAI 使用官方服务端点，可沿用机器已经配置的 loopback 代理；应用不安装代理或修改系统网络。模型名称以实际账户支持为准。

## 当前支持的操作

- 查询已提供的工程结构、选择对象及按需读取的 MIDI 信息。
- 工程速度、轨名、轨道音量/声像/静音/独奏，须符合所选范围。
- 新建音频/乐器/Bus轨；在既有乐器轨创建空 MIDI 片段，移动已有片段。
- 选区内或明确指定片段的移调、起音量化（含1/16384）、力度调整。
- 一次原子批次应用、状态回读和受版本保护的一步撤销。

新对象 ID 由 DAW 生成，在同一个方案中不能先建轨再假定其 ID 建片段；应用后下一次要求才能引用它。当前不生成/理解音频，不控制任意插件、录音、保存或删除文件，不提供自动保存/恢复或长期自主创作。回读成功说明数据符合方案，实际声音仍需试听。

## 费用、数据和异常

每次要求最多4次模型请求，每次最多2048输出token；界面显示实际返回的请求/token计数，不推算未知价格。没有自动付费重试。取消阻止后续步骤，已经发往服务的请求可能仍收费；失败请求不一定能取得token用量。

模型接收要求、近期对话、有界工程结构/选择和按需 MIDI 统计/少量示例。音频文件、插件预设、本机文件路径不随这些请求上传；完整音符在本地处理。模型私有推理状态仅用于当前调用循环，不进入界面、对话记录或审计。

方案绑定工程ID、音乐revision和选区revision。超时可能发生在 DAW 已收到命令之后，因此写通道停止且不自动重放；先查看 DAW 的实际状态。助手断开不会关闭工程。关闭侧栏只收起；需要退出时在 DAW 正常保存并关闭。

审计位于 `%LOCALAPPDATA%\E-musician\agent\audit.jsonl`，保留当前及轮转的有界元数据日志，包含任务/方案ID、摘要哈希、版本和结果；不保存密钥、完整对话、音符或模型思考。这不是工程恢复文件。
