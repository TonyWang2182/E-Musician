# E-musician 0.6.0 快速上手

按0.6.0 Windows实际界面标签编写，日期：2026-10-29。新版Release已通过5/5自动回归，人工操作和听感待[短测](review/2026-10-29-daily-workflow/MANUAL-CHECK.md)。完整结果见[0.6.0记录](verification/2026-10-29-v060/RESULTS.md)；0.5.2不包含本页新增控件。

## 启动与打开工程

正常 Release 入口是 `E:\E-musician\build\bin\Release\E-musician.exe`。已有对应版本产物时，在项目目录的 PowerShell 中运行：

```powershell
Set-Location -LiteralPath 'E:\E-musician'
python scripts/dev.py run --config Release --note "日常使用"
```

没有产物时按 [构建说明](BUILDING.md)先完成构建。点击顶部 `open`，或按 **Ctrl+O**，选择 `.emproj` 文件。测试工程在 `E:\E-musician\test-projects`。搬动工程时，把 `歌曲.emproj` 与同目录的 `歌曲.assets` 文件夹一起复制；打开的是 `.emproj`，不要选素材目录。插件程序和外部音色库需要另外安装。

`new` / **Ctrl+N** 创建默认 **120 BPM、4/4** 的空工程。点击底部的 `120 BPM` 可调整速度、拍号和循环范围；改变BPM不会自动拉伸音频。

## 导入音频与查看全部轨道

1. 点击 `add...` → `Import audio... (WAV / MP3)`，可一次选多个文件；也可把音频文件拖入主窗。等待底部导入任务完成。
2. 中央只有一个多轨编曲时间轴。滚轮上下看轨道，**Shift+滚轮**横移，**Ctrl+滚轮**缩放；`-` / `+` 调整缩放，`fit` 显示整个工程。
3. 点击片段选中；拖主体移动，拖边缘裁剪。`edit` 菜单提供分割、剪切/复制/粘贴、删除和 `Clip properties...`；音频片段上方拖柄调整淡入/淡出。
4. 点击标尺定位；底部 `play` / **Space** 播放或暂停，`stop` 停止并归零。轨头 `M` 是静音，`S` 是独奏；点击轨道本身不会独奏。

`details` 展开所选轨道/片段属性。`source` 打开下方的源音频波形；`close editor` 收起下方区域。这里的 `source` 是查看源文件，不是音源分离。

## 标尺、吸附、选区与剪贴板

`bars` / `seconds` / `both` 只切换时间显示；`snap` 独立开关吸附，**Ctrl+4** 切换，拖动时 **Alt** 临时绕过。网格可选自适应、小节、1/4–1/16384、1/8 或 1/16 三连音，默认 1/16。固定网格不会随缩放改变；过密格线会减少绘制，自适应网格会随缩放调整精度。小节线、拍线与细分线按当前 BPM 和拍号换算，靠近其他片段边缘也可吸附。切标尺或吸附不改变工程内容。

`details` 的片段起点、`Clip properties...` 和 BPM 对话框内的循环起止位置随标尺单位输入。`bars` / `both` 使用 **小节:拍:tick**，例如 `2:1:000`；小节和拍从 1 开始，每个拍号单位拍有 960 tick（000–959）。片段长度可用小节数，允许小数；`seconds` 使用秒。音频源偏移和淡入/淡出仍按秒输入。Enter 或 `set` 应用起点，Escape 恢复原值。

| 动作 | 操作和结果 |
|---|---|
| 选择整个片段 | 单击；Ctrl/Shift+单击切换多选；从空白处拖矩形框选，Ctrl+框选保留原选择 |
| 时间选区 | **Shift+拖标尺**；同时选中所有与该时间范围相交的完整片段 |
| 剪切、复制、粘贴 | 编曲区域 **Ctrl+X / C / V**，或 `edit` 菜单；先选目标轨、定位播放头，再粘贴 |
| 分割、重复、删除 | 在播放头按 **S** 分割当前片段；**Ctrl+D** 将所选片段组重复到后方；**Delete** 删除所选完整片段 |
| 循环所选范围 | **Ctrl+L**；优先使用时间选区，否则使用所选片段整体范围，并开启循环；可拖标尺下方循环括号两端或整体 |
| 导航 | 编曲区域 **Home** 到零点、**End** 到工程末尾、左右键按当前网格前后移动；标尺可定位到最后片段之后 |
| 跟随播放 | 打开 `follow`；手动滚动、缩放或编辑会暂停跟随，重新开始播放或重新启用 `follow` 后恢复 |

**时间选区不会裁出片段内部的一部分。** 复制、剪切和删除作用于完整片段；只想处理某段内容时，先在两端分割。成组跨轨移动保留相对行距，目标各轨必须与原轨类型匹配。

片段剪贴板保存复制时的内容，可在同一工程中编辑/删除源片段后继续粘贴。粘贴将最早片段放到播放头，并将最上方原轨对齐目标轨，保留各轨间隔；缺少目标轨、类型不兼容或越界会整体拒绝，需先建好目标轨。新片段有新 ID，音频复用已有素材，不复制插件或音色。纯 MIDI 片段组在改 BPM 后粘贴仍保留拍间距；混合音频/MIDI 组保留复制时的秒间距。一次剪切或粘贴可一步 Undo。它不是 Windows 系统剪贴板，不跨工程，也不保存到工程文件；新建/打开工程或退出应用后清空。

## MIDI片段与已有乐器插件

1. `add...` → `New MIDI / instrument track`，选中这条轨道。
2. 点击该轨头的 `devices`，在底部 `devices` 页点击 `add plug-in...`。插件浏览窗中先用 `scan installed`，或 `scan folder...` 扫描安装目录。
3. 确认浏览窗顶部目标是这条MIDI轨，选一个标为 `instrument` 的乐器，点击 `add >`。回到底部设备链，选插件再点 `open` 打开它的原生窗口；`bypass` 旁路，`up` / `down` 调整链顺序。
4. 在标尺定位，`add...` → `New 4-bar MIDI clip at playhead`。已有MIDI文件可用 `Import MIDI...`。
5. 双击MIDI片段打开**底部钢琴卷帘**。空白网格双击写音符，或打开 `draw B` / 按 **B**，单击空白处写音符。已有音符仍可选择、拖动改音高/位置、拖边缘改长度；Shift+单击多选，Ctrl+A 全选。选中后用 `velocity`、`quantize`、`-1 st` / `+1 st` 调整。`drum steps` 展开16步鼓编辑，仍需合适的鼓乐器插件发声。

钢琴卷帘有自己的 `snap` 开关和网格精度（最细1/16384，含三连音），**Ctrl+4** 在当前聚焦编辑区切换，Alt 临时自由拖动。多音符移动按拖动的音符吸附，其他音符保留相对间距。

在钢琴卷帘内用 `copy` / `cut` / `paste` 或 **Ctrl+C/X/V** 操作所选音符；它与编曲片段剪贴板分开。点击卷帘标尺或空白位置设置可见插入标记；未设置时按播放头在该片段内的位置粘贴。最早音符对齐插入位置并遵循本区 `snap`，其余相对时值、音高、长度、力度和通道保持。成功后选中新音符，标记移到这组音符末尾，整个粘贴可一步 Undo。

同一工程切换 MIDI 片段后仍可粘贴，复制后改动或删除源音符不会改变已复制内容。目标片段太短、通道不兼容或超出音符数量限制时会整体拒绝，查看底部错误，先扩大片段或调整插入点；不会静默丢掉一部分音符。音符剪贴板只保留在当前编辑器/应用会话中，换工程或退出后清空，不与外部程序交换 MIDI。

没有加载可用乐器的MIDI轨不会发声。当前插件入口为 Windows x64 VST2/VST3；具体插件、版本和音色是否正常，以实际加载和验证结果为准。

## 设置声卡并录音

1. 停止播放，点顶部 `audio settings`。在 `Driver` 选驱动，ASIO在 `Device` 选厂商声卡；分离输入/输出的驱动分别选 `Input` 和 `Output`。点 `apply`，以面板 `Active:` 显示的实际配置为准。
2. 更换设备后先应用默认配置，再选它实际支持的 `Sample rate` / `Buffer size` 并应用。失败时面板显示错误及回读值。**关闭设置窗后才能开始录音。** MIDI键盘输入在下一步选择，无需在此寻找MIDI总开关。
3. 音频录音先建 `New audio track`；MIDI录音建乐器轨，并按上节加载乐器。选轨 → 轨头 `devices` → 底部 `I/O + sends`，在 `recording input` 下拉框选麦克风/线路或MIDI端口，再点 `arm record`，按钮变为 `armed`。已选输入后也可用轨头 `R` 切换预备录制。
4. 0.13.5起每轨单独设置 `monitor off/on`：只有 **On** 才听到该轨实时输入；Off即使R开启也不监听，但可以录音。R关闭、On开启可以练习而不录入。多轨共用键盘时开关独立，选中某轨不会改变其他轨；已有片段播放不受监听开关控制。旧Auto按Off兼容，实际构建/测试状态见CONTEXT。
5. 关闭底部 `loop`，定位录音起点。需要预备拍时先停止播放，打开 `count-in` 并选 `1 bar`、`2 bars` 或 `4 bars`，再点 `rec`。界面显示剩余拍数；预备期间 `stop` 取消，不提交空录音。未开预备拍则直接线性录音。
6. 点 `stop` 结束录音。等待 `Finishing recording...` 消失，片段提交后再保存。预备、录音及收尾时编辑、保存和设备切换暂不可用；一次录制可整体Undo。

当前没有循环叠录/comping流程。多个MIDI端口名称相似时，选择实际收到键盘数据的端口；端口能列出不等于已经验证实体演奏。

## 节拍器、预备拍与运行状态

`click` 开关节拍器，旁边 `...` 设置独立音量（-36 到 0 dB）及 `Only sound while recording`。按当前拍号强调小节首拍；节拍器用于监听，不写入内部录音或 WAV 导出。启用节拍器且输出设备可用时，空工程也可点播放练习。

`count-in` 开关独立于 `click`，关掉后记住所选 1/2/4 小节。**预备拍只在停止状态开始录音时生效；普通播放没有预备拍，播放中按录音会直接起录。** 倒数按拍号分母对应的拍计数，例如 6/8 的一小节是 6 拍。节拍器和预备拍设置保存在本机应用偏好中，重启后沿用，不随 `.emproj` 传给别人，也不占 Undo 或把工程标为未保存。

轨头显示输出电平，已连接的音频输入另有输入电平；右侧 `OUT` 显示主输出。过载提示保留到点击 `OUT` 重置；这会清除各电平保持状态，不重置 xruns。MIDI 轨的输出电平来自乐器音频，不是按键计数。

状态栏 `RAM` 是整个 DAW 进程的工作集（含同进程插件），约每秒刷新；悬停可看私有提交量，不是某个插件独占内存。`DSP` 是音频回调负载，**不是整台电脑的 CPU 百分比**；`xruns` 是设备/宿主报告的欠载计数，增加不等于每次都已经人工听到爆音。以这些指标辅助排查，不能单凭低读数判断所有插件和长工程性能已通过。

## Bus、发送与自动化

**分组/发送：** `add...` → `New bus / group track`。选原轨，打开 `devices` → `I/O + sends`：`track output` 可选 `Master output` 或已建Bus；`send to bus` 选目标后点 `add send`，下方选择该发送，调整dB、`post-fader` / `pre-fader`，或用 `bypass send`、`remove send`。效果器可加在Bus的设备链上。会产生反馈环的连接会被拒绝。

**自动化：** 选轨 → `devices` → `automation`，从下拉框选轨道音量/声像或当前插件提供的参数。曲线区双击加点，拖点移动，**Alt+上下拖点**调整该点后面的曲线，选点按 **Delete** 删除。`bypass lane` 暂停该曲线，`delete lane` 删除整条；右上 `master` 切换到主输出的设备/自动化。横轴为工程秒，纵轴为归一化百分比。当前支持画曲线和播放，不提供Touch/Latch/Write录制模式。

## 保存、撤销与导出

`save` / **Ctrl+S** 保存，首次会选择 `.emproj` 位置；`save as` / **Ctrl+Shift+S** 另存为。保存中按钮显示 `saving...`，顶部状态为 `Saving...`；等到 **`Saved`** 才表示当前状态已保存。`Unsaved changes` 表示仍有新编辑；`Save failed - retry` 时查看底部具体错误，再重试。连续按Ctrl+S会合并请求，不需要反复点击；保存期间的新编辑仍需保存。关闭前等待保存结束。

`undo` / **Ctrl+Z** 撤销，`redo` / **Ctrl+Y** 恢复；重开工程后不保留撤销历史。本轮按用户要求不增加自动保存和恢复，重要版本可以用 `save as` 留副本。

`export` 菜单可选 `Export project WAV...`、`Export loop range WAV...`、`Export project WAV at real-time speed...`，或导出完整/所选MIDI片段。WAV选好路径后，设置起止秒、采样率、位深和尾音，再点 `apply`；等待后台任务完成。实时速度选项是渲染方式，不是声卡内录；**MP3目前仅导入，不导出。**

## Agent接口入口

接口使用本地JSONL，与GUI共用工程命令。最小示例在项目目录运行：

```powershell
python scripts/agent_client.py --exe build/bin/Release/E-musician.exe --demo build/agent-demo
```

示例会启动专用进程，创建测试音符并导出MIDI，不操作另一已打开的DAW窗口。需要同屏控制可用 `E-musician.exe --control-stdio --show` 配合客户端。请求、版本冲突和异步任务完成状态见 [Agent API](AGENT_API.md)；当前没有内置模型或聊天面板。
