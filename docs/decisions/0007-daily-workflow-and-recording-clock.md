# ADR 0007：编辑坐标、录音时钟与运行状态

日期：2026-10-29。状态：采纳，随0.6.0实施；验证结果以当次构建档案为准。

## 背景

用户已确认基础音频/MIDI录制和混合工程可用，下一步需要可预测的剪辑吸附、音乐/秒标尺、节拍器、预备拍及资源显示。旧界面把标尺与吸附合并，细分格线与实际落点不一致。实际模型Agent暂缓，但新增编辑继续使用现有命令和Undo。

## 决定

1. 引擎和MIDI以四分音符为一拍；显示按拍号分母计算拍。`EditGrid.hpp`统一网格策略，`MusicalPosition.hpp`统一音乐位置，格式`小节:拍:刻度`，小节/拍从1开始，每个显示拍960刻度。切换标尺、网格或吸附不改音乐数据。属性表单未修改的显示值保留原始精度。
2. 片段剪贴板在进程内保留不可变描述与素材引用，限当前工程。粘贴生成新对象ID，共用素材，一次Undo；纯MIDI组保持拍间距，音频/MIDI混合组保持秒间距。时间选区当前操作整段相交片段，不实现部分选区切片复制。JSONL粘贴必须带剪贴板身份，避免并发复制后误贴另一个内容。
3. 预备拍沿Tracktion原生音频时钟执行，从停止状态起录时生效。UI只读倒数，不靠定时器延迟启动录音。取消不接纳take；跨录音边界的持续音符裁到首拍，独立持续控制器有保守追赶白名单，Bank/RPN/NRPN等有顺序语义的操作不合成重放。
4. 节拍器/预备拍设置是应用偏好，通过EngineSession命令更新，不进入工程schema、revision、dirty或Undo。预备拍与普通click开关独立；click只送设备cue路径，不进入内部录音或离线渲染。固定引擎相关修改以可复查补丁及哈希管理，不手工修改未记录依赖。
5. 电平读原生LevelMeasurer，消息线程低频采集有界快照；RAM每秒查询一次进程工作集与私有提交量，不在音频回调查询OS。移除轨道/设备或切换Edit时清理监听。DSP表示音频处理负载，不等于整机CPU。
6. 自动测试显式offline；嵌套EngineSession也使用内存设置，不改用户声卡配置、不打开物理设备。合成原生音频图测试与用户硬件/听感验收分别记录。

## 影响与边界

保持单个Edit和schema4，无额外可写音乐模型、自动保存、恢复、TempoMap或模型服务。播放光标允许定位到片段以外的空白区域，上限48小时；未来录音不再被旧内容长度限制。现有音频保持秒长度和原速；切换音乐标尺不提供Warp。

后续Agent可以查询能力、快照和任务，通过现有身份/版本/幂等/撤销契约调用这些操作。实际模型规划、授权策略、结果解释和Agent UI需另行开发与验收。
