# ADR0008：细网格、可见范围绘制与文件精度

日期：2026-10-29。状态：实现，验证结果以CONTEXT和0.6.1报告为准。

用户要求1/16384全音符编辑、三级标尺、线型反馈和流畅缩放。只扩展菜单会被32倍缩放、400px/beat、1ms分割和960PPQN导出限制阻断。

决定共享1/4096quarterbeat网格下界。标尺层级为bar、bar.beat、bar.beat.quarter；不改原Inspector解析协议。固定吸附值与像素绘线间距独立，深度缩放目标最细一格至少16px，界面尺寸保持视口大小，避免构造超宽组件。

绘制依据可见范围和提交快照索引；音频细节用有界worker窗口、取消/代际校验与LRU发布，不在paint读取媒体。密集音符明确降采样预览，数据和完整选择不删减。波形插值显示不承诺独立的sample editor或亚采样DSP。

原生保存保持完整双精度。SMF用4096PPQN支持二进制最细网格；960和4096的最小公倍数61440超过标准正PPQN上界32767，不能宣称所有旧960位置与细二进制网格同时无损。自由/三连音使用最近tick与正时长保护。为48h/300BPM使用局部wide tick writer，固定音符/控制器格式、合法VLQ和空文本间隔填充，保留严格parser及原子写入。

不增加schema、不接模型、不加自动保存，不把离线组件性能替代实体设备听感。配置/构建/测试记录由Recorder维护；人工短测由用户完成。
