# 原生装置能力目录与统一设备链

状态：已实施，离线验证通过；真实桌面与设备待验。

问题：原生装置参数分别存在宿主、面板和模型方案中，仅提示模型“可以操作”不能保证参数完整、范围正确或实际修改成功。用户需要按轨道真实顺序查看和操作设备。

决定：下方设备条仅投影引擎快照中的有序 slot，选择和添加重用现有控制层；不维护独立可写链。宿主公开版本化类型、参数范围、读写和作用域等目录，Agent 在设备任务前比对自身方案能力；不匹配时拒绝相关操作。Agent 的相对参数由本地基于已读取快照编译成完整状态，保留版本、选区、审批和执行后回读约束。

边界：目录与一致性检查是变更门槛，不会自动生成音乐语义、参数控件或 DSP。Sampler/Rack 目前仍限已载入样本、project 范围、单异步参数操作，模型不能提供路径；设备参数接口不等于宿主自动化。实时线程不可读写文件、网络、解析 JSON、等待锁或按需分配；Delay/Reverb 的存储在控制线程为相应实例准备。第三方插件编辑器及自身声库加载不受本注册表管理。[验证与限制](../review/2026-11-02-device-chain-agent/RESULTS.md)。
