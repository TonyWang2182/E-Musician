# 分析工作区、和弦轨和界面语言

日期：2026-11-05。状态：已采用；自动验证和人工验收分别见本轮 RESULTS。

## 决定

1. 分离和转录接受后复用普通音频/MIDI 轨。和弦使用标尺下方的独立可视轨道，投影既有 `EM_CHORDS`，不创建参与混音的空音轨，也不另存一份音乐状态。
2. 和弦轨与编曲区共用时间坐标；多次分析按 analysisId 选择，双击区域打开对应结果页。修正、保存和 Undo 继续走既有命令。当前和弦选择是界面状态，不宣称已扩展 Agent 的通用选择上下文。
3. 分析下栏只显示必要参数、图形候选和简短状态。详细模型、评分、来源及失败信息留在数据/日志。精确时间范围和转录阈值移入 Options 弹层，小窗口仍能使用。
4. Worker 生成固定 128 点波形，界面绘制不读音频文件；和弦快照按 revision 缓存，可见区遍历不随鼠标拖动重新查询完整工程。没有新推理、JSON 或文件工作进入实时音频回调。
5. 六轨模型独立注册，保留四轨默认；Agent 的工具校验、导入计划、轨数预算和完成回读都按同一真实候选数量。转录乐器选项只约束已有模型的音域；扩展和弦词表仍是模板算法。算法可运行、听感和准确率不混为一项验收。
6. 界面语言是本机偏好，默认为英文，Settings 可切换中文。只翻译明确标记的静态文案；用户音乐名称、插件内容和模型回复不扫描替换。切换不重启引擎或 Agent，不写工程、不改变设备选择。源代码中文字符串显式按 UTF-8 解码。

## 代价和后续边界

独立和弦轨暂不承载发声、自动伴奏或复杂爵士理论编辑。Agent 仍按源片段读取和修正和弦，点击和弦块不会自动成为完整 Agent 音乐选区。六轨中的钢琴/吉他允许存在串音；扩展词表不会消除转位与同音集合歧义。新角色和新标签保存在 schema 5，旧版遇到不支持的数据明确拒绝，不做静默降级。第三方插件与部分历史诊断的语言保持原样。
