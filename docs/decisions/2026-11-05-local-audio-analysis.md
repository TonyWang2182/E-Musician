## 决策

- 手动 Analyze 面板和 Agent 调用同一组分析命令。手动功能无需聊天模型或 API 密钥。
- DAW 冻结素材 ID、片段位置/裁剪、范围及 BPM。文件线程启动固定本地脚本和注册解释器，模型不能指定命令或文件路径。运行库、权重、缓存位于 E 盘，不随 Git 发布。
- 一个重推理任务；文件/模型工作不进入音频线程。提供限额、取消、进程退出错误和一小时超时。普通保存允许与推理并行。录音前应先完成或取消重分析；本批没有任意 PyTorch 推理的无损暂停/恢复。
- `ready` 仅代表候选可读。接受时后台重新校验源文件和候选哈希、准备素材及 DTO，控制线程再次核对工程版本/来源后一次提交。工程改变则拒绝并可重试，不半导入。
- 秒是分析时间基准，按已确认 BPM 转拍；不自动量化、改速度或替换原音频。
- 四个 stem 保留可信 `analysis_role`，重命名不改变角色。Basic Pitch 不接受 drums 或混合 other；它不是鼓分类器。新 MIDI 轨仅有音符，需要另选乐器。首批不恢复弯音、踏板或原音色。
- 和弦是权威 ValueTree 中可保存/修改/撤销的标签区间，不生成伴奏。24 种大/小三和弦加 N，分数不是正确概率。
- 有分析数据的工程用 schema 5，普通无分析工程仍存 schema 4。0.8.1 明确拒绝 schema 5，不能静默丢数据。
- 已接受音频先复制到独立 session assets，保存时进入工程 `.assets`。候选缓存不是自动保存/恢复，不能清理 Undo/Redo 引用的素材。
- 试听用有限大小 PCM 环形缓冲，后台解码/重采样，音频回调只复制样本与读取原子状态。

## 验收与限制

环境探针、编译、合同测试、真实模型管线、识别质量、ASIO 共存听感分别验收。HTDemucs 权重仅用于本机评估，官方当前再分发许可尚未明确；源码 MIT 不代表权重也获准分发。GPU 默认路径须有本机 RTX 3050 4 GB 实测，不能以 CUDA 安装成功代替推理通过。候选历史有界，程序退出后不恢复未接受结果。
