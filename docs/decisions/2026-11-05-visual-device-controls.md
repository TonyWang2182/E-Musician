# 可视参数控制与装置状态兼容

日期：2026-11-05。状态：已实现，最终验证见本轮 RESULTS。

## 控制路径

原生装置使用共享旋钮样式、数值框和专用图形。图形只表达权威参数/本地手势预览，不保存第二份工程状态。图形与旋钮松手后通过同一个 EngineSession 命令、工程/选择版本和 Undo 提交；Agent 读取同一状态和版本化能力目录，再编译成对应命令。

EQ 图和音频渲染共用核心滤波响应；压缩器 GR 来自音频处理的原子读数。Delay/Reverb/LFO 图是有明确说明的静态参数示意，没有假实时频谱。绘制计算有界，不触发读盘或网络。

## 声音与兼容

EQ 每段增加显式形状字段，旧状态缺失时保留原有首低架、尾高架、中间峰型。Sampler/Rack 每垫增加 Attack/Release/One-shot，旧默认分别为 3ms、30ms、采样器 Gate/鼓组 One-shot。参数不等于新增全 ADSR、Warp、多采样层或节拍同步能力。

由于旧程序会忽略未知字段，仅保持 version 1 会导致新工程在旧程序中静默变声。因此保存时：EQ 采用不同于旧固定形状的设置、采样采用不同于旧固定包络/模式的设置，装置状态升级为 version 2；新程序兼容 1/2，旧程序会明确拒绝 2。恢复全部旧默认可回到 1。工程总 schema 和传输协议不变；无需重写用户已有工程。

采样参数编辑可复用已发布的不可变 PCM，只在非音频线程复制配置。显式换样本和重开仍读盘/校验，保存继续核对已播放内容 hash，避免已变更外部文件被静默替换。新 bank 仍按已有生命周期发布和退役；不通过共享指针在音频回调释放大块数据。

## 几何

音符和片段仅改变矩形绘制区域与相应命中区域；不修改音乐时间、长度、采样偏移或量化。片段轨道保留 1px 分隔线。缩放时继续按可见区域裁剪。
