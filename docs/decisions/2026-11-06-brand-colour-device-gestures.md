# 0.11：品牌资源、轨道颜色与效果器手势

日期 2026-11-06；用户已批准轻色工作区图与树乐师 Logo。实现状态及验证以本轮 review/RESULTS.md 为准。

## 一个工程，多种入口

`GUI / Agent → set_track_colour {track_id, colour} → Edit 的 emColour → TrackSnapshot / 存档 → 编曲、卷帘、Agent 回读`。颜色为严格的 `#RRGGBB`，规范化为大写；空串恢复默认。缺少字段的旧工程继续打开。颜色是轨道身份，不借用 mute/solo/arm 或选中状态。纯颜色操作和批次只更新元数据与 Undo，不替换 Edit、音乐 clip 或共享只读音符数组；混合音乐编辑批次保留原流程。没有新增工程 schema。

库列表、项目概览、装置链和 Agent 目标均为快照投影。资源库添加与拖放复用已有命令，轨道右键和 Edit 共用颜色命令。无效拖放位置不回退到当前选轨；用户编辑工程后，过期颜色菜单按 revision 拒绝提交。概览只定位视图，不改播放头、音符或工程。

## 可试听、可取消的效果手势

原生效果使用 `begin_native_effect_gesture → update_native_effect_gesture → end_native_effect_gesture / cancel_native_effect_gesture`。控制层拥有短期预览事务，预览通过已有参数发布机制送入原 DSP；工程快照和 dirty 不变。提交才修改权威状态并形成一次 Undo。取消、失焦、换装置、保存及其他冲突音乐编辑恢复已提交状态，过期 token 不能覆盖新修改。Agent 的单次 `set_native_effect` 复用轻量提交；不对模型开放任意底层内存写入。

DSP 侧对相关参数/系数过渡做平滑。频谱为效果器实际输出的有界采集；UI 可见时以 20 Hz 读取并做 2048 点 FFT，无音频回调 FFT、网络、JSON 或磁盘操作。采集请求有租约，面板停止读取后自动停采。GR 继续使用现有原子计量。它们不是精确母带计量仪。Sampler/Rack 的换样与 voice 生命周期未在本轮承诺无缝。

## 视图与品牌资源

用户批准的 PNG 原件不改写；通过 JUCE BinaryData 缓存解码用于左上角和约 0.9 秒的启动淡入淡出，通过 CMake/JUCE 图标生成嵌入 Windows PE。启动图不伪造任务进度，点击/按键可跳过；后台、离屏测试、插件辅助进程不播放启动动画。旧版本输出目录不覆盖。

顶部播放/录音及编辑控制、左侧可搜索库、编曲矩形对象、可调整下栏和可开关 Agent 固定职责。窄窗口 Agent 覆盖右侧，宽窗口保留独立列；被临时收起的 Library 不保留可点却无反馈的按钮。标签采用无衬线，数值用等宽字，颜色区分身份而非承担唯一状态提示。没有实现的收藏夹、段落标签、Session 网格不从设计图复制假数据。

## 验证边界

保存重开、一次 Undo、旧工程兼容、状态冲突、离线 DSP 和不同尺寸组件截图属于自动检查；真实 Windows DPI/输入法/鼠标、M-Audio ASIO、MIDI 长待机、听感仍要人工验证。性能数据必须附具体工作负载和机器，离线倍速不能等价为实时零爆音保证。
