# ADR：生成候选、远程计算和本地工程

状态：实现中；2026-11-06。关联 [批次计划](../review/2026-11-06-cloud-generation/PLAN.md)。

## 决策

- 生成是一组独立公共命令，不伪造源音频或复用分离结果类型。GUI/Agent 调用同一宿主入口，音频线程只播放已经接受的本地资产。
- 本批先实现 ACE 文字/歌词生成；没有音频上传或原工程同步需求。SSH 专用密钥认证，网关仅绑定远端 loopback；本机后台 helper 拥有短生命周期隧道和网络请求，主 UI 不等候网络。
- 云端 SQLite 保存任务与幂等请求，一次一个重任务；重连查询相同 ID，参数改变必须新 ID。进程中断明确记录 interrupted，不冒充可续算。
- 云端生成完成不等于工程已改变。后台下载验证完整 SHA、文件大小、PCM WAV 元数据，再原子发布候选。试听/取消/接受分开，接受新建轨道并保留一次 Undo。
- 生成条件与实际音乐分开：BPM/时长/拍号是模型条件，输出仍按实际音频长度落轨，不自动裁剪或拉伸。后续用户可用已有节拍/Warp 功能对齐。
- 生成来源记录独立于需要源 clip 的分析来源。新含生成记录工程使用 schema7；旧普通工程保持原 schema。原0.11可执行文件保留，遇schema7明确拒绝，不静默丢来源。
- 已接受素材由本地 session/project assets 管理。候选云端路径/URL不可成为已保存工程唯一资产。关租卡后仍可保存、重开、离线渲染已有生成轨。
- 未接受候选与远端任务历史不等于工程自动保存。任务取消可能需要等待当前推理返回后丢弃结果；服务不可用时保留取消未确认记录，不能表示远端一定已经停止收费。
- 本机现有语言模型设置与音乐生成运行环境分离；不把 API 密钥写入工程、Git 或模型服务。

## 证据边界

只有真实云端 CUDA 推理、整链文件与宿主接受/保存/重开通过后标为对应已验证。模拟 worker、合成音频、离线声卡以及真实语言模型测试各自标明；听感、实际ASIO共存与跨实例恢复不能从编译成功推断。
