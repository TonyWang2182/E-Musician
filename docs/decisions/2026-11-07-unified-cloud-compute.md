# ADR：多模型共享单 GPU 任务服务

2026-11-07。状态：实现已进入验证；验收范围以本轮 RESULTS 为准。

## 背景

模型部署和短推理不等于 DAW 可用。旧 ACE 服务独占驻留模型，新增分析脚本无法安全与它各自调度 GPU；转录 CC、多乐器、和弦标签和综合分析输出也超出现有单轨 notes 契约。

## 决定

- 云端新增 loopback 18082 / protocol 2，SSH 认证边界保持。所有生成和云 MIR 进入同一个 SQLite 幂等队列。服务持有原 ACE service lock，防止两套队列同时拥有 GPU。迁移只在已识别服务无活动任务时进行，旧脚本和数据库不删。
- 每个重任务在该模型已固定的独立 Python 环境启动专有进程组，结束后释放。共享 GPU lock 也协调原有评测；超时/取消/资源不足只清理自身任务。父服务退出时由 Linux parent-death 和进程所有权标记处理子树。
- 选择每任务进程隔离，接受加载与文件校验的冷启动成本，以避免不同 PyTorch/依赖冲突、驻留显存争抢和取消不可靠。此版不宣称最佳云端热延迟，不用 `empty_cache` 冒充卸载模型。
- 模型和位置是不同选择。明确模型/位置不隐式换模型；Auto 根据宿主登记的可用默认项选路，由任务开始的实时远端能力确认。云端断线不会变成本地推理或自行租卡。旧本地四/六轨、Basic Pitch、Chroma、Beat This 保留。
- 音频只上传冻结选区 WAV 和内容 SHA，不上传工程、插件、聊天密钥。源 offset/Warp/工程 revision 留本地。上传与下载都有大小、几何、SHA、取消与路径边界，返回结果是候选，不是直接修改工程。
- 模型返回原始输出和规范秒时基。CC 原值、多乐器/程序号、复杂和弦原标签、拍点及结构按真实输出保留。没有预测的力度、可信度或速度不补成“分析事实”。YuE2 的时长是语义 token 预算；自然终止与截断分开记录。
- 原生 GUI、Agent 共用 start/result/accept，接受重新检查来源和 revision，单次 Undo。新分析来源与综合注释由相应 schema 保存；已接受资产、音符和 CC 本地持久化，云端离线不影响编辑/回放/导出。
- 新版本二进制输出到 bin-0.13.0，旧 0.12.1 保留。模型权重继续只在云端，只有本批功能所需结果下载本地；不把整套模型备份混入接入过程。

## 验证与限制

协议/模拟故障、Linux 真实子树清理、服务重连和真实模型推理、宿主工程操作、物理 ASIO/听感是不同证据层。自动检查不能证明复杂爵士识别或分离准确率，也不能代表物理鼠标/声卡延迟。
