# 共享弹出主题与Agent语言投影

日期：2026-11-08；状态：已实现；证据入口：[本轮结果](../review/2026-11-08-cloud-reconnect-ui/RESULTS.md)。

## 问题与决策

工作区已有局部主题，但JUCE未关联组件的菜单、警告框及部分设备控件仍使用默认深色外观。抽出应用持有的WorkspaceLookAndFeel作为全局默认，工作区与设备主题继承它；完整设置V4 ColourScheme并覆盖菜单、选项气泡和警告框的绘制。仅统一展示，保存回调、结果ID、工程命令和实时线程不变。Windows文件选择器和第三方插件自有界面保留原样。

Agent原系统提示明确要求中文，网页只翻译静态标签，后端进度和计划也固定中文。新增请求头X-Agent-Language，任务开始冻结locale并约束模型回复，HTTP输出按locale翻译带来源标记的系统文本。用户文本、歌词、名称、命令字段保持原始值；模型明确被要求用另一语言时尊重用户要求。已有历史对话不强制重写。

## 取舍与验证

共享绘制保留JUCE的布局与异步生命周期，避免重新实现保存状态机。语言投影不引入第二份可写音乐状态，也不改变工具权限。新文案应显式提供英文与中文；未知中文后端异常使用安全英文概述并保留内部诊断，后续按实际报错补齐翻译。不能据两次真实回答推断所有模型永远遵守语言要求。

验证分别覆盖原生组件/按钮语义、双语响应/用户数据保留、真实LLM语言探针及克隆云端整链；组件离屏倍率截图不等于物理显示器DPI或听感验收。云端克隆继续使用原protocol 2与已固定release，不因界面维护重建模型环境或复制权重。
