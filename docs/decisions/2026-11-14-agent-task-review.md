# Agent 任务审阅和有界生成选择

状态：已实现；真实语言模型补验受 API quota 阻断。适用 0.13.4。

用户看到一个任务和真实处理阶段，候选完成后看到简短结果、试听/查看、Apply；实际回读成功后才显示已应用，并提供一次 Undo。历史对话、模型路线、逐步命令、token 用量和诊断保留在折叠详情。变化对象、作用范围、过期保护和模型截断提示保持可见。

统一 runtime 状态仍是网页的唯一状态来源。下载中总进度曾出现 1 但多个文件仍在传输，因此本版用不定长活动条和真实阶段文字，不把已耗时或子任务百分比伪装成总体完成率。

生成候选最近六项保留在 helper 内存的只读投影中，按工程筛选，不持久化第二份工程状态。`POST /api/generation/select` 接受真实 result_id 和用户 Scope，后台重新读取原生候选、冻结当前修订/范围、重新编译导入方案；无需 LLM 或再次生成。该接口不应用、不扩大范围，之后沿用原来的 Preview/Apply/Undo 和身份/hash 校验。跨工程、变速/拍号、过期或已接受候选拒绝；普通无关编辑后可重新审阅，旧方案不能直接应用。helper 重启后快捷列表不恢复；原生生成面板的既有任务机制保持。

API 429 仅有 exact `insufficient_quota` 类型/代码时单独提示计费问题。最多读取 8192 字节响应，仅做允许值匹配，既不回显错误 message、原文、header，也不自动收费重试。其他 429 仍使用通用用量/频率提示。

GUI / Agent / 控制接口继续复用原生公共命令。新列表、HTTP 和解析均在 helper/控制线程；音频回调、工程 schema、DSP 与云端部署不变。Beats 为当前仅本地提供的能力，切入时重设 Local，防止继承隐藏的 Cloud 筛选。
