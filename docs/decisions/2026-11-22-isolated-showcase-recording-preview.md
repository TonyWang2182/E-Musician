# 独立拍摄包与真实录音预览

日期：2026-11-22。状态：实现，验收结果以对应 review 记录为准。

## 决定

日常版继续独立运行，不依赖模型服务。录音增强版保留 0.13.6 的录音与设备语义，只新增瞬态显示层：复用 Tracktion 后台写盘线程发布的缩略图，消息线程管理 take 身份，编曲窗口绘制当前可见范围。新显示层不写工程修订、不生成 Undo，不在实时回调读取文件、解析 JSON 或处理界面。

停止后将正在录音的缩略图保留到正式 clip 峰缓存准备完成；预备拍、取消、错误、Undo 和换工程清除失效身份。时间边界采用引擎录音时钟；峰缓存的量化长度不替代样本数，延迟补偿不重复执行。

用户需要在没有 SSH/API 的情况下重拍已有工作流。使用单独的编译开关 `EMUSICIAN_SHOWCASE` 和独立 EXE/本地 profile 实现，不允许工程 JSON 或模型内容开启该路径。生产配置、密钥、插件缓存、历史和录音目录不与该包共用；插件目录仅复制已存在的 catalog，未安装或扫描新插件。

拍摄版用有限英文指令匹配 manifest 中的场景，不声称具备新的语言理解。历史模型 result 和媒体按 SHA256 校验，源片段、范围、采样率、速度与参数必须匹配。复用真实原生候选验证、Preview、Apply、Undo/Redo、Warp 和工程保存。用户点击 Apply 才写入工程，和弦仍在 Analysis 手动接受。

等待由 manifest 配置，仅用于拍摄节奏；来源与非推理标识保留在内部记录。应用和视频可以保持干净的视觉呈现，讲解不得把历史结果、静态截图、预设等待或抽象演奏动效当作新模型推理、实时性能测试或真人录音。

## 验收边界

合成 PCM 生产管线测试验证真实峰值与生命周期；不代替实体声卡发声、长时间录音和听感。有限场景联测验证宿主工程行为；不代替自然语言模型能力或音乐质量。大视频及用户音频放 E 盘交付目录，源代码、输入哈希、命令、结果与限制进入开发档案。
