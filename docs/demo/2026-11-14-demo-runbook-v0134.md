本稿配套[四分钟中英分镜](2026-11-12-four-minute-demo.md)，实际提示词正文继续使用[六条英文操作稿](2026-11-14-demo-operations.md)及 E 盘 `prompts` 中逐字相同的 TXT。本页补充新侧栏、双模型选择、手动节拍、Jungle 素材和动效。

**验证边界：六条音乐模型与工程接受/撤销/保存重开的实际通路均已通过；ACE 的原样英文 Agent 指令通过真实 GPT，其余语言指令因 `insufficient_quota` 尚未补验。中文界面和确定性工具流程已测，不等于中文自然语言理解已经真实 API 验收。** 0.13.3 模型证据见[真实结果](../review/2026-11-14-demo-rehearsal/RESULTS.md)，0.13.4 软件检查见[本轮结果](../review/2026-11-14-agent-demo-v0134/RESULTS.md)。不要把下方未补验提示词称为全部真实 Agent 已通过。

## 0. API 与启动

- 新版入口：`E:/MusicAgent&DAW/Start E-musician 0.13.4.cmd`。先保存并正常关闭旧 DAW，再用此入口打开。旧版文件保留，没有强制关闭用户工程。
- API 设置：Agent 顶部 **Model settings / 模型设置 → Provider: OpenAI → Connection and API key / 连接与密钥 → API key → Save settings / 保存设置**。0.13.3 顶部入口显示当前模型名字；0.13.4 显示 Model settings。
- Base URL：`https://api.openai.com/v1`；Model 暂用 `gpt-5-mini`。密钥留空保留旧值；不要把密钥粘到对话输入框。
- 已记录错误是 HTTP429、`insufficient_quota`，不能仅凭它区分余额不足与项目/组织限额。去[API 计费](https://platform.openai.com/account/billing)和[用量限制](https://platform.openai.com/account/limits)检查；仅重建同一账户密钥通常不能修复额度问题。新项目密钥在[平台项目设置](https://platform.openai.com/settings/organization)中选择项目 → API Keys。参见[官方用量说明](https://help.openai.com/en/articles/6614457-troubleshooting-api-usage-and-spend-limits)。
- 用户目前仍在处理 API，本轮没有继续收费重试、没有切换到别的语言服务。音乐模型服务与 GPT API 分开，手动分析/生成可继续；不能把手动录屏说成 Agent 操作。

## 1. 新侧栏怎么用

发送一条指令 → 看“正在规划/生成/分析/下载”等实际阶段及活动条 → 查看简短结果 → 必要时 **Preview / 试听** → **Apply / 应用** → **Undo this change / 撤销这次修改**。停止等待不等于已确认云端停止，界面保留真实取消状态。

作用范围始终可见。本演示用独立工程副本、唯一英文轨名、**Whole project / 整个工程**，避免对正式作品扩大范围。处理中不编辑目标来源；若工程或选区改变，旧方案不能应用。只有后台确认修改并回读后才报告成功。

技术信息在 **Task details / 任务详情**，完整旧对话在 **Full conversation / 完整对话**。字幕不必拍这些内容。不定长条表示还在工作，没有假百分比或推测剩余时间。

## 2. Demo 1：两个模型生成 → 选择一个 → 四轨分离

### 生成（YuE2 与 ACE）

新建 90 BPM、4/4 的演示工程，播放头 0 秒，停止播放，Scope 选 Whole project。先复制 `prompts/D1-YuE2.txt` 发送，结果出现后试听，点 Stop preview，但先不 Apply。随后复制 `prompts/D1-ACE.txt` 发送。两条完整英文见[原样提示词](2026-11-14-demo-operations.md)；只把模型名不同的两条按顺序发送，不同时发两个 GPU 任务。新版开始下一项任务时也会停止旧候选试听，避免隐藏控件后仍在播放。

音乐内容都是 warm Rhodes、clean guitar、rounded bass、laid-back drums、intimate female lead vocal；32 秒预算，包含下列原创歌词和短 intro/verse/chorus 结构要求：

```text
[Verse]
We found a rhythm in the quiet
Let the city fade away
[Chorus]
Stay until the morning light
Hold this feeling through the night
```

1. 第二个结果完成后，**Choose a generation / 选择生成结果** 中分别选择 YuE2 或 ACE，点 Preview 对比；切换会重做校验，不重生成、不调用 GPT。
2. 选择喜欢的那个，再点 Apply。工程应只新增该候选的一条音频轨；另一个仍可在当前会话中重新选择、另行接受。已加入候选不允许重复添加。
3. 点击 Undo 撤销这次导入；需要恢复用 DAW 的 Redo。不要为了恢复已经导入过的候选再点添加。
4. 把最终选择的轨道改名 **Chosen Neo Soul**，保存工程，然后分离。

限制：列表最多保留最近六项，属于当前 helper 会话，重启后不恢复。切换工程/BPM/拍号会使相关候选不可直接使用。单个候选即使在最后语言总结阶段失败，仍可通过选择结果恢复审阅。0.13.3 实测 YuE2 长度 31.9987 秒且 token_budget 截断，ACE 32 秒、结束原因未知；不能承诺自然结尾或严格段落。64 小节 90 BPM / 4/4 需约 170.67 秒，超过当前单任务 120 秒上限。

已经生成的两个结果可直接打开 `OPEN-FIRST.md` 对应工程试听，无需重新付费。它们来自各自独立工程，不会自动成为同一会话下的候选对比列表。新列表经过软件测试，真实 GPT 双结果同工程彩排仍待 API 恢复。

### 四轨分离

唯一来源轨名 Chosen Neo Soul、Scope Whole project，发送：

```text
Use cloud SCNet to separate the only audio clip on the track named Chosen Neo Soul into vocals, drums, bass, and other. Keep the original audio unchanged. Prepare a four-track import proposal for review; do not apply it yet.
```

等待 → 查看四轨结果 → Apply。原始混音轨 Mute，四个新轨先 Mute，再按 **drums → bass → other → vocals** 逐段取消静音。不要同时放原混音造成虚假的叠加效果。Ctrl+S 保存；Undo 可撤销一次四轨导入。

手动替代：选音频 clip → analyze → Separate → Cloud → scnet → Analyze → Add tracks。模型为 **SCNet**，固定四轨。实测源是 32 秒 ACE 音频，四个音频资产均校验并保存重开通过，分离质量需试听。

## 3. Demo 2：New Light 和弦轨

新建 120 BPM、4/4 工程，导入 `sources/new-light-60-84.wav`（24 秒摘段），轨名 **New Light Source**、Scope Whole project。发送：

```text
Use cloud ChordMini to identify the chords in the only audio clip on the track named New Light Source. Show the detected labels and prepare a chord-track import proposal for review. Keep the source audio and project tempo unchanged.
```

等待 → 展开分析结果查看标签 → Apply → 编曲区出现和弦轨。先保存 `D2-NewLight-Chords`，再做 Warp。该摘段实测返回 15 个和弦区段；这是检测输出，不是已人工认定全部和弦正确。

手动替代：选音频 clip → analyze → Chords → Cloud → chordmini → Options（Start 0，Length 24）→ Analyze → Add chord track。

## 4. Demo 2：在 Analysis 手动检测节拍并应用 Warp

继续选 New Light Source 的音频 clip，保持项目 120 BPM。0.13.4 已修复继承 Cloud 筛选的问题，可以从 Chords 直接切 Beats。

1. 顶部 **analyze → Beats**；当前使用本地 **Beat This! / beat-this-final0**。
2. **Auto meter**；Options 中 Start = 0、Length = 24，然后 Done → Analyze。
3. 看 **BPM**、**First / s** 和拍线。本摘段实测约 **125 BPM、4/4、首个小节拍 1.68 秒**。人工试听若判断半速/倍速，用 `/2`、`x2` 修正；拍线可重新指定首小节拍。
4. 点 **Align audio**：保持项目速度，用保音高 Warp 对齐音频，保留开头。**Use this tempo** 会改项目 BPM/拍号，本镜头不要点它。
5. 到 source 查看 Warp，开节拍器试听，再 Undo/Redo 对照；另存 `D2-NewLight-Aligned`。实测 ratio 0.96，24 秒音频变为 25 秒，clip 起点 0.25 秒，首小节拍落到 2 秒；已有 15 段和弦同步映射。

这是固定比例保音高拉伸，不是任何幅度下都无音质损失，也不是逐瞬态的自由变速 Warp。若操作旧 0.13.3，先在 Chords 把 Cloud 改 Local 再切 Beats；新入口不需要这一步。

## 5. Demo 3：Tea for Two 钢琴转 MIDI

新建 120 BPM / 4/4，导入 `sources/tea-piano-20-36.wav`（16 秒已分离钢琴），轨名 **Tea Piano Source**、Scope Whole project。发送：

```text
Use cloud TransKun to transcribe the only audio clip on the track named Tea Piano Source to MIDI. Preserve any pedal events actually returned by the model. Prepare a MIDI-track import proposal for review. Keep the source audio unchanged.
```

等待 → 检查音符结果 → Apply → 双击新增 MIDI clip 打开卷帘，可 expand / Ctrl+Alt+E 展开。给 MIDI 轨加载已验证的钢琴音源，Mute 原始钢琴后回放；A/B 时一次只放一个。修改一个音符并撤销，展示它是真实可编辑数据。

实测：132 音符、17 CC（16 个 CC64、1 个 CC67）、1 个 program change；保存重开通过。MIDI 不自带钢琴声音，音符/踏板准确性仍需人工听。手动：analyze → MIDI → Cloud → transkun → Analyze → Add MIDI track。

## 6. Demo 4：Jungle 素材、上色和基础混音

先取 `jungle-materials` 中打包素材与说明，详见[JUNGLE-MATERIALS](../review/2026-11-14-agent-demo-v0134/JUNGLE-MATERIALS.md)。在线现成 Ableton Jungle 工程作为单独个人参考，不能在本 DAW 原生打开 .als。便携包是许可允许的 WAV/MID 等素材集合，适合手动导入；此轮没有冒充已经完成的 Jungle 成曲。

准备阶段轨名统一为 **Drums、Bass、Pad、Vocal**：Drum Rack 加载 kick36 / snare38 / closed-hat42 / open-hat46，Sampler 根音按包内表格填写，导入从第 1 拍起的 ADAPTED MIDI；人声可用提供的 CC0 短词，也另录一条实唱 take。现有下载 MIDI 原件含很长前置空白，便携包同时保留原件与明确标记的整理副本。选择已验证的第三方插件，提前加载好；不在拍摄时扫描大型插件。

新版实际离线宿主已导入全部17个WAV和7个MIDI，核对24轨/277音符、Rack的8个真实采样、两个Sampler根音与SHA，并通过保存重开。当前Rack垫位范围36–51，因此可选Cowbell放51；不要套用GM的56。这个检查工程只是素材校验，不是已编好成曲；实际播放和听感仍请人工确认。

完整颜色/混音操作稿与软件验证见[COLOUR-MIX](../review/2026-11-14-agent-demo-v0134/COLOUR-MIX.md)。只做保守初始电平/声像，不宣称模型听过音频或已自动专业混音。真实 GPT 原样提示词仍待额度恢复补验。

录音镜头沿用原分镜：预先设输入、只 Arm 目标轨、Monitor 合理、1 bar 预备拍，连续保留 Record → 预备拍 → 实际演奏/唱 → Stop。停止并完成写入后取消 Arm、回放、保存重开。170 BPM 一小节约 1.41 秒，两小节约 2.82 秒，可用剩余镜头时间保留键盘/话筒动作；不要拿预写片段冒充实录。

## 开拍前最短验收

1. 英文/中文各发送一个短任务，看到真实阶段、简短结果；技术信息默认收起，不能发生错误语言系统文案混入。
2. 同一工程生成两结果并切换试听，确认只 Apply 所选结果；应用后 Undo 恢复，保存重开资产仍在。API 未好时只验手动流程，标记待补 Agent。
3. 分离4轨、和弦轨、Beats/Warp、钢琴MIDI各保存一个副本；试听检查串音、标签、首拍、漏音/多音。
4. Drum Rack每垫、Sampler根音/包络、指定插件、键盘/人声输入都实际出声；录屏能同时录到 DAW 声音。
5. 先录 10 秒测试视频再拍正式片。处理等待可剪短并标 `Processing time shortened`；使用已生成结果时标 `Previously generated result`。
