## 拍摄前准备

- 前三个工程使用独立 showcase-v1 英文版：New ideas、New Light、Tea for Two；最后一段用 0.13.6 中的 test drive 拍摄副本。不要覆盖原工程。
- 拍前完整走一遍 Preview → Apply → Undo/Redo；检查三工程可重置、来源选择正确、原曲与候选不叠放。
- 录屏至少 1080p30；若需要局部放大，建议更高分辨率录屏。系统/DAW 输出与麦克风分开录，先回看 10 秒测试。ASIO 能听见不代表录屏有声音。
- Keyscape、BM-VOID、BM-HUSTLE 预加载；拍摄中不要重新扫描插件。录音输入/Arm/Monitor 由使用者预先检查，确保仅目标轨录制。
- 清理通知、桌面弹窗和悬浮宠物；保留清晰指针和真实按钮状态。不要露出 API 密钥、SSH 或个人文件。
- 六个背景仅在各章起始占 0.6–1 秒，已包含在段落时长内，不另加时长。开场动效 8 秒，其余 10 秒为产品预告；片尾 12 秒。
- 旁白使用本机 Microsoft Zira 的离线合成稿；英文 WAV、分镜 WAV、英文 SRT 和中文对照 SRT 均可替换。纯试听镜头不叠旁白或额外 BGM。

## 内部制作事实与范围

前三章拍摄版复用已存在的模型产物，并设置可重复的等待节奏；本次不连接 SSH、不调用 API、不运行新的云端推理。界面保持干净，脚本不将等待演出称为真实推理耗时，不将既有结果说成此次重新生成。生成只称短片段，不承诺完整 64 小节或严格段落。质量、复杂自然语言理解与通用性能不由这套固定流程证明。来源文件/哈希由素材清单记录。

本交付是可录制程序配套的拍摄与剪辑素材包，不包含最终合成的四分钟实录视频。New Light / Tea for Two 的曲名与表演来源保留在内部资料中，公开分发前由使用者确认适当的使用范围；不会把这些音乐称为原创或随开源代码分发。
