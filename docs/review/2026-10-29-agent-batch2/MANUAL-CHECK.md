# Agent 第二批：人工短测

目标版本 DAW 0.8.0 / Agent 0.3.0。自动证据见[RESULTS](../../verification/2026-10-29-agent-batch2/RESULTS.md)。以下在真实桌面由用户执行；离线原生/浏览器测试不能代替设备听感、鼠标、键盘或中文输入法验收。

## 打开与保留工程

先在现有0.7窗口保存工程、由用户正常关闭，再双击 E:\\MusicAgent&DAW\\Start E-musician Agent.cmd。标题应是0.8.0；工具栏Agent或Ctrl+Shift+A开关侧栏。使用新建测试工程，避免覆盖自己的编曲。

## 1. 一句话完成连续创建

范围选“整个工程”，输入：
> 新建一条叫测试旋律的MIDI轨，从第1小节开始创建4小节片段。写入4个音符C4、D4、E4、G4，依次从第1、2、3、4拍开始，每个1拍，力度80。保持120BPM。

先检查预览轨名、位置、长度，展开“新增音符明细”核对每个音符；确认前编曲区不应变化。应用后应出现轨与片段，双击看到4个音符。新轨没有自动加载乐器，所以此项先核对音符，不以声音为标准。立即点“撤销本次修改”，整条新轨和片段应一并消失；再点DAW顶部redo，应恢复原片段和音符。完成这两步后再手动加载已验证的乐器试听。加载插件属于新的手动编辑，此后助手不会跨过它撤销旧方案，应使用DAW自己的撤销历史。

## 2. 复制并只改副本

自行准备一个有音符的4小节片段，选中它，以“当前选择”要求：
> 复制这个片段到第5小节，把副本全部音符力度改为60，原片段保持不变。

先检查预览，再应用。双击原片段与副本比较力度；撤销一次应删除副本并保留原片段。选中单个音符时，再要求修改整个片段，应拒绝超出选择范围，或要求明确扩大范围。

## 3. 常用编辑与错误阻止

单独测试移动、缩短音符、删除指定音符、裁剪/删除片段，核对预览与撤销。裁剪带有MIDI控制器/CC的片段本批会明确拒绝。方案显示后先手动改工程或换音乐选区，再点应用，应拒绝旧方案。不要为通过检查而隐藏修改。

## 4. 暂停、继续和取消

提出任务后点“暂停”。已有网络请求可能需要先返回；此时显示“等待”，不会把暂停误称为已中断网络。进入已暂停后工程不变，可继续，也可取消。暂停期间手动编辑工程，再继续，应拒绝过期上下文。应用中的原子提交不可暂停/取消；只能完成后撤销。

## 5. 日常稳定性

用已验证的真实多轨工程播放时展开/收起侧栏、输入中文、滚动方案；检查DAW快捷键与聊天输入的焦点。保存、关闭并重开自行编辑的测试工程，检查音符与插件状态。记录是否有卡顿、断音、输入丢失或错误提示，而不是仅以程序启动判断性能通过。

反馈请注明版本、步骤、预览内容、结果及错误原文。若发生“已提交但回读未完成”，先检查工程，不反复点应用。
