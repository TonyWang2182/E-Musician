# 0.6.0 新增功能短测

由用户操作GUI和试听。以下是待验证步骤，不是已通过记录；不需要重新做此前已确认的全部插件/混合工程测试。

1. 打开`build/bin/Release/E-musician.exe`，确认标题为0.6.0。用测试工程的另存副本操作。
2. 选`bars`、开`snap`、网格`1/16`，拖一个片段到第2小节；切`seconds`后再拖，吸附应仍开启。Alt拖动可自由落点，Undo恢复。切`both`查看两种标尺。
3. 框选片段，Ctrl+C；点击目标最上方轨道的轨头，再点击标尺第5小节，Ctrl+V。轨道类型与原组一致且目标轨足够时应整组粘贴，一次Undo撤销。Shift拖标尺后Ctrl+L，应循环该范围；拖循环两端、打开follow观察播放。
4. 双击MIDI片段，B切画笔、单击写音符；选音符Ctrl+C，点击卷帘后方空白处Ctrl+V，Undo撤销。目标片段需足够长。
5. 用已验证的键盘/Keyscape轨，停止状态、Arm开、loop关；打开click试听强弱拍，启用count-in并选1小节，按rec。倒数完后录音，Stop后直接保存和回放。再试2小节预备途中Stop，应取消且不新增空片段。可关click保留count-in，倒数仍应发声。
6. 播放时看轨道/Master电平、RAM和DSP；停止后电平回落，点击OUT清峰值。只要反馈这次新增功能中遇到的异常及当时版本即可。

时间选区当前复制/删除相交的整段片段；部分内容先分割。count-in只在从停止起录时生效，播放中点击rec立即起录。节拍器不应出现在内部录制音频或导出WAV中；麦克风在外放时拾取扬声器声音属于实际输入，试听可用耳机。

本轮未新增自动保存/恢复，测试副本请手动保存。新版本的硬件听感、操作便利性及长时间实际负载不能由离线回归代替。
