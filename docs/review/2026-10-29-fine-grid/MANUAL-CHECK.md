# 0.6.1人工验证

使用Release：`E:/E-musician/build/bin/Release/E-musician.exe`。标题应为0.6.1。先关闭旧窗口，选择新建工程或对已有工程Save As为新的测试副本；不要覆盖常用工程。自动测试为离线组件/命令验证，不替代以下真实鼠标、显示与听感。

1. **三级标尺**：在编曲窗口用`+`或`Ctrl+滚轮`逐步放大。远处显示`1、2…`，放大后显示`1.1、1.2…`，再放大显示`1.1.1、1.1.2…`；继续放大不出现第四级名称，细网格刻度继续增加。4/4第三层为十六分音符；6/8等拍号按分母拍再分四份。属性框仍兼容原`bar:beat:tick`格式。
2. **开关吸附**：点击编曲空白区域取得焦点，按`Ctrl+4`。Snap关时垂直时间网格为虚线，开时为实线；拖动片段观察关时自由移动、开时对齐网格/邻近边缘。钢琴卷帘也做同样操作，作用于当前编辑区；两处Snap各自独立。文本输入时不抢快捷键。
3. **最细编辑**：MIDI片段下方网格选择`1/16384`，`Ctrl+滚轮`放大到相邻细线可分辨。画一个最短音符，移动一格、伸长一格，再Undo。编曲网格也有相同选项，可移动、裁边或分割很短片段。缩小时仅减少绘制线条，固定吸附精度不变；不是把整屏绘满16384条线。
4. **缩放与拖动**：围绕某个音符/音频瞬态反复`Ctrl+滚轮`，锚点应基本留在鼠标下；`Shift+滚轮`水平移动，`fit`回到工程全貌。长工程末端重复一次；窗口不应卡死、位置不应突然大跳。音频深度缩放可短暂等待后台细节，随后显示该局部波形。
5. **保存与导出**：保留上述细音符，Save As到新的测试工程，导出MIDI到新文件，关闭重开并导入刚导出的MIDI。音符数量和相对位置应保留，原工程能正常播放。最细二进制网格使用4096PPQN导出；关闭Snap后的任意位置和三连音仍按MIDI tick就近舍入，正时长最少1tick。
6. **实际体验**：在已验证的音频+插件MIDI测试副本播放时缩放、拖片段、Undo，观察RAM、界面响应及听感。无需重复全部旧插件/设备矩阵；若异常，记录标题版本、窗口大小、拍号、网格、缩放位置、音符/片段数量和复现步骤。

密集钢琴卷帘超过绘制预算时会提示`dense preview: zoom in`，音符数据和完整选择仍保留；放大查看细节。合成性能证据与实际范围以最终RESULTS.md为准；本文不是已完成的人工验收。
