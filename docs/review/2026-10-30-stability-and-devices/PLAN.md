# 稳定性修复与原生装置路线（2026-10-30）

## 本轮：用户报告，调查中

1. 长时间待机后 MIDI 键盘无声：分别检查输入设备、音频流及休眠/热插拔恢复，避免无条件重启用户设备。真实待机和设备演奏需人工验收。
2. MIDI Monitor On 影响其他轨：检查物理输入与轨道监听之间的隔离、Arm/Auto/Off 语义及录音路径，回归多轨共享同一键盘。
3. 插件浏览/加载卡住或空白：检查扫描、选择、实例化、编辑器生命周期、失败提示和可重试性；第三方插件实例化可能阻塞或崩溃，不能凭空承诺兼容全部插件。

现有用户运行记录和工程保留；自动测试不替代实际键盘、设备、插件和休眠验证。原始构建日志写入 build-logs，摘要与证据写入 docs/builds 和 DEVLOG。

## 原生装置：后续规划，尚未实现

目标是自有、可保存和可控的音源与效果器，参考 Live 的工作流程和功能类别，不宣称复制其音色、专有算法或预设。Live 参考：[乐器](https://www.ableton.com/en/manual/live-instrument-reference/)、[效果器](https://www.ableton.com/en/live-manual/12/live-audio-effect-reference/)、[装置延迟](https://help.ableton.com/hc/en-us/articles/360001820360-Viewing-the-latency-of-a-plugin-or-Live-device)。

### 先做共同底座

现状：DAW 控制协议已有第三方插件的添加、移除、排序、旁路、参数分页读取及设置等命令（见 [AGENT_API](../../AGENT_API.md)）；Agent 第二批未将它们全部开放为模型可执行动作。应复用并核验现有语义，补充原生装置描述与兼容性，不另建一套可写工程状态。

- 装置注册表：稳定类型 ID、版本、输入输出、默认预设、参数 ID/单位/范围/步长、读写能力和自动化描述；新旧版本迁移和缺失装置保留数据。
- 轨道装置链及统一命令：添加、移除、排序、旁路、参数读取/修改、预设装载，均支持校验、版本冲突、Undo/Redo、保存重开；GUI 和 Agent 共用同一权威工程状态。先限定 Agent 可操作范围和确认策略，再开放模型工具；不把当前 Agent 的 19 项编辑动作误称已支持装置。
- 实时安全：音频回调不分配、访问磁盘或网络、等待锁；样本载入/波表准备/预设解析后台完成，音频线程只消费安全发布的数据。明确参数平滑、复音数上限、延迟报告/补偿、尾音和旁路行为。
- 验收：离线信号与频响/包络、极值与 NaN、状态往返、撤销和自动化、设备组合/长时播放、CPU/内存/爆音；分别记录机器、采样率、缓冲区、负载和真实听感。具体数字通过实测制定，不预设性能达标。

### 首要顺序（均为计划）

1. **基础减法合成器**（Drift/Analog 类）：振荡器、滤波、ADSR、力度、复音、基础预设，让 MIDI 工程不依赖外部音源。高级模拟建模及 MPE 后置。
2. **简易采样器**（Simpler 类）：异步导入、单样本触发与音高映射、起止点、包络；先支持可控基础格式和 one-shot，时间伸缩/切片与大型多采样后置。
3. **鼓组 Rack**（Drum Rack 类）：先做 16 pad 与音符映射，复用采样器、每 pad 音量/静音；多层、复杂链/输出后续逐步补齐。
4. **参数均衡器**（EQ Eight 类）：先实现稳定多段滤波、图形和参数自动化，频谱显示与过采样依性能结果分阶段；不是声称等同 EQ Eight。
5. **压缩器**（Compressor 类）：阈值、比率、attack/release、增益、表头；侧链依赖路由和延迟补偿，单独验收。Glue 风格与高级建模后置。
6. **Delay、Reverb、Auto Filter**：先按通用实用算法逐一交付；同步节拍、尾音、湿干与自动化均须测试。

第二阶段考虑 FM 合成（Operator 类）、Wavetable、多采样 Sampler；它们分别依赖调制/抗混叠、波表处理、样本管理与流式读取。Glue 风格压缩与高级模拟建模也放在后续，避免先做大量界面却缺少可靠音频核心。

### Agent 如何使用

装置底座提供可枚举的类型及带单位参数、工程中实例和当前值；Agent 读取上下文，提出明确的新增/调参计划，做范围与版本校验、展示预览并经用户确认后，以同一命令事务执行并回读。不能用听感词直接假装确定参数：需要可解释的映射、可撤销结果和以后独立的音频分析能力。预设和用户样本的来源与授权需记录，模型请求不默认上传用户音频。
