# 采样试听与效果器人工检查

使用本轮候选程序和一份新测试工程。把音箱或耳机音量调低；本清单由用户在真实声卡和桌面上操作，自动化离线测试不能代替。

1. 在 MIDI 轨打开 Sampler，加载一段 WAV；停止时间线后按装置里的 **play**，再按 **stop**，确认能单独听到和停止采样。Rack 给多个 pad 分别加载 WAV，切换 pad 后分别试听，确认不播放其他 pad；切换 pad、关闭装置或切轨时确认没有残留声音。
2. 反复打开和关闭底部设备面板，切换有采样的 pad，观察波形出现速度；如果仍明显卡顿，请记录 WAV 文件大小、采样长度、大概等待时间、操作步骤。确认采样范围拖动及声音没有错位。
3. 选中音轨或 MIDI 轨，进入 devices → **built-in effects...**，添加 EQ Eight。选一个频段，拖动曲线上的圆点或参数滑块，确认声音和曲线变化；点击 band on/off，尝试撤销、重做。
4. 添加 Compressor，设置 threshold、ratio、attack、release、makeup，确认音量动态变化；通过设备链 open 再次打开。按面板里的 master 切换到主轨，重复添加和打开 EQ 或 Compressor。
5. 同一 MIDI 轨同时放 Sampler/Rack 和效果器；保存到新工程，关闭并重开，检查采样、鼓垫、效果器顺序和参数是否保留，并播放比较。不要覆盖原测试工程。
6. Agent 已配置模型时，可让其添加 EQ 并调节某一频段，检查方案、应用和回读。Sampler/Rack 已加载采样的参数操作目前限 **project / 整个工程范围**、单次一个动作；模型无法自行挑选本机采样文件。

如有问题，记录使用的候选程序路径、工程副本、声卡/缓冲、设备、具体操作和错误文字；卡顿时记录是否只在首次加载发生。
