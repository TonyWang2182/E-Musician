# 采样试听、波形响应与原生效果器

状态：候选实现与离线自动验证完成，真实桌面、声卡和听感待用户验收。以原有未提交工作为基线并保留用户工程；独立目录构建。自动测试和早期未纳管测试记录见 [RESULTS](RESULTS.md)，未操作用户桌面。

## 目标与边界

1. 定位并降低主窗口设备 dock 中波形出现的延迟；区分装置读取、UI 刷新和波形准备，不以未测指标代替性能结论；保留内容 hash、一致性、过期过滤和后台 I/O。
2. Sampler 与 Rack 的选中 pad 以明确试听/停止方式独立发声，不依赖轨道录音或项目播放，不修改音符/工程；安全处理关闭、切轨、样本替换及忙状态。
3. 参考已确认黑白工作区设计，实现自有实用多段 EQ 与压缩器：可视化与真实声音、参数/开关、效果链、保存/重开、Undo/Redo 和导出一致；不得声称 Ableton 专有算法或听感一致。
4. 设备提供可枚举类型、参数/单位/范围及一致的原生命令；Agent 需真实具备读取、预览、受范围和 revision 保护的编辑能力，明确异步任务与失败边界，未经完成的部分不得声称模型可操作。避免向模型暴露任意文件路径或无审查执行。

## 验证

DSP 和宿主分层测：EQ 频率响应/旁路、压缩动态与参数边界，采样试听非零及停止、并发/设备切换、波形请求时序，状态保存重开与撤销、离线导出、已有 DAW/Agent 回归；视觉用合成组件截图检查。硬件听感和用户真实 GUI 单独人工验收。性能记录机器、构建、采样率、buffer、负载和测量方式；无人测数据时保留为目标。
