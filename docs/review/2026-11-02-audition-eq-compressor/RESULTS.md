# 试听、波形与原生效果器：记录与验收边界

状态：候选已实现，离线自动验证通过；真实 Windows 桌面、ASIO、MIDI 键盘与听感待用户验收。原工程和旧版二进制保留；候选程序 `build/audition-effects/bin/Release/E-musician.exe`，支持点击 Agent 按钮或以 `--agent` 启动。不要用旧程序覆盖含新装置的工程，旧构建未声明兼容新装置状态。

## 已实现

- 波形优先复用与已加载采样内容匹配的不可变 PCM，在后台生成有界概览；载入期间提高状态检查频率。无法取得合适的 PCM 时保留经过内容哈希验证的文件回退。无真实设备或用户素材的速度数据，不宣称解决所有卡顿。
- Sampler 与 Rack 的当前 pad 提供 play/stop，试听不修改工程或录制 MIDI，通过当前轨道音频链；切换 pad、关闭/隐藏面板时停止。静音、solo、轨道音量、效果器及输出状态仍影响试听。
- 自有 EQ Eight：首尾为高/低架，中间六段为峰值；逐段开关、频率、增益、Q，静态频响曲线可拖动。自有 Compressor：立体声关联峰值检测，阈值、比率、攻击、释放、补偿；曲线为参数推导的静态输入/输出关系，不是实时电平或增益衰减。两者可用于轨道和主轨，可保存、重开、撤销、重做和离线导出；不是 Ableton 算法复刻。
- Agent 可读取并通过审阅方案添加或设置轨道和主轨 EQ/Compressor，批次与回读通过统一命令执行。对已加载采样的 Sampler/Rack 参数提供工程范围单动作，等待异步任务真正提交和回读；不允许模型选择文件路径、装载样本或把采样动作混入其他原子批次。主轨方案限工程范围。未测试真实模型的音乐判断。
