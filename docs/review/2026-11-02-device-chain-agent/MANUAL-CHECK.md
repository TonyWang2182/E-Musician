# 人工验证：设备链、采样与 Agent

先用本轮 `build/device-chain/bin/Release/E-musician.exe` 打开测试工程副本。新版保存的 Auto Filter、Delay、Reverb 状态，旧版程序不保证能打开；不要覆盖重要旧工程。

1. 新建或选择 MIDI 轨，点击顶部 **devices**。下方应出现按实际顺序排列的装置和左右按钮；用 **+ Sampler / + Rack / + EQ / + Comp / + FX / + VST** 添加，Sampler 和 Rack 在 MIDI 轨互斥；`+ FX` 包含 Stereo Delay、Reverb、Auto Filter。点击设备或左右按钮应查看对应装置；排序/旁路/移除仍在 devices 轨道面板里。
2. Sampler/Rack 加载已知 WAV，分别从右侧设备按钮和设备浏览器 Open 进入；检查波形和试听能否正常出现，最小化／恢复、切换轨道再回来，确认不一直显示 loading。若复现，记录 WAV 文件大小、加载时长和入口。
3. 在已有音频上试听 Compressor 的 dry/wet 与实际 GR 读数；增加 Delay、Reverb、Auto Filter，分别调整时间/衰减/低高通与 LFO，检查声音变化。保存为新工程、关闭重开，检查参数、顺序、试听和撤销。对上述效果在主轨也做一次。
4. 点击 Agent 侧栏选择 OpenAI 中等推理；先测试“把当前轨 EQ 第三段增益提高 3 dB，其他频段不变”，在方案里核对目标和数值，再应用并撤销。其他测试和失败反馈格式见 [Agent 排查手册](../2026-11-02-agent-diagnostics/README.md)。更高强度可能增加等待与费用。
5. 如果一直加载的其实是 Keyscape 或其他第三方插件的**插件自带声库**，在同一轨、同一实例和音色下，分别用右侧按钮与设备浏览器 Open 测试；记录精确插件名、两个入口的画面/加载时间、错误提示和声库位置是否可访问。代码审查显示两个入口最终调用相同宿主接口，原因尚未证实，不应把原生面板修复当成第三方声库问题已解决。

请留意装置参数的数值框及画面：自动合成截图在完整主窗口里有数值未显示的现象，而独立组件截图正常；真实桌面是否也会这样尚未确认。
