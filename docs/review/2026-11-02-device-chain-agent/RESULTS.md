## 本轮实际变化

- 设备链：底部设备条按当前轨或主轨真实 slot 顺序列出装置；可以直接选择或用左右按钮打开，提供 Sampler、Rack、EQ、Comp、+FX 和 VST 入口。`+FX` 可加 Delay、Reverb、Auto Filter。设备链是快照视图，实际添加仍由原生命令完成；旁路/删除/排序仍在 devices 轨道面板。第三方设备选择打开其原生编辑器，不模拟该插件界面。
- 原生采样显示：修复 NativeDevicePanel 自身可见但父层隐藏时定时器停止后无法恢复，临时读取失败也会重试；增加父层隐藏、显式关闭的行为测试。并非已证实 Keyscape 等第三方声库问题：两个入口经 `open_plugin` 找到同一插件实例并调用相同编辑器接口，但用户环境有不同现象，尚缺真实插件 A/B 证据。`open_plugin` 新增显式轨道归属检查，防止使用错误轨 ID 打开设备。
- 装置：压缩器加入 dry/wet、平滑和真实 wet 路径压缩量读数，停止处理时显示不可用。新增原创 Stereo Delay、Reverb 与 Auto Filter，参数分别包括时间/反馈/干湿、衰减/阻尼/干湿、低高通/截止/Q/LFO/干湿。它们有真实 DSP、轨道/主轨、UI、保存重开、撤销、旁路、离线导出与 Agent 参数；不是 Ableton 算法复刻。原生 EQ 仍只有首尾架、中间峰型；Sampler 仍为单 WAV，Rack 仍是固定 16 垫。
- Agent：支持读取真实状态后做单参数绝对值或相对值修改，其余参数由本地补齐并保留；可配置 OpenAI 推理强度（低/中/高，默认中）。宿主版本化能力目录与 Agent 类型、参数范围和权限不一致时拒绝相关操作；这不是自动编写新装置控制逻辑，增加装置仍需同步注册、定义语义并通过一致性测试。Sampler/Rack 仍只能对已加载采样做 project 范围单动作参数修改，模型不能选路径或新建采样器。

## 性能和限制

Lenovo 21HX / i7-13700H / Release，48 kHz 立体声、256 帧、合成输入、8 段有增益 EQ 加 Compressor 的单链离线测试：106.667 秒音频处理用墙钟 0.681 秒（[记录](../../builds/20261102T080420.615597Z-0bfbb1d81d.json)）。无声卡、磁盘、第三方插件或其他轨道；不代表真实项目 CPU、延迟或卡顿。Delay 每实例预分配约 5.9 MiB，Reverb 约 0.88 MiB；尚无大量实例及 ASIO 长时间压力数据。效果器极端重入仍可能跳过一块处理。

此前提到的 Operator、Wavetable、Analog、Drift、完整多采样 Sampler、完整 Rack、Glue Compressor 等均未完成，不能视为已达 Ableton 的深度或完整度。Auto Filter 是低高通双二阶及简易 LFO，无侧链/节拍同步；Delay 无拍速同步/乒乓；Reverb 是原创近似算法。旧版程序不保证可打开本轮新效果器工程；音频听感、UI 数值显示、键鼠、真实 ASIO 和 Keyscape 待人工核验。
