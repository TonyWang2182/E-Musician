# 钢琴卷帘与原生装置工作区：实施计划

状态：实现和离线验证通过，真实桌面/设备与听感待人工验证，详见 [RESULTS](RESULTS.md)。用户已确认 [三张概念图](../../design/2026-11-02-device-concepts/README.md) 的方向；原有未提交更改和测试工程已保留。

## 本轮范围

1. MIDI 编辑器在主窗口可展开与返回，保留现有选择、音符、网格、吸附、播放控制和编辑语义；编辑前后的工程数据及焦点不被重置。
2. 原生采样器 / 鼓组嵌入主窗口工作区，不再依赖小弹窗。采样器展示真实波形、根音、起止和增益；鼓组展示从底部 36–39 开始递增的 4×4 鼓垫，以及选中垫样本、波形和控制。
3. 波形峰值后台获取并有界缓存，界面绘制不做磁盘读写或完整 PCM 遍历；波形手柄使用预览，释放后通过统一命令提交并校验工程版本。加载中、空样本、失败、切换轨/工程等状态明确。
4. GUI 使用同一 Edit 和原有命令；不另造可写音频状态，不把图中示意波形或数据当成实际内容。性能保持目标，需要独立测量才能给结论。

## 验证与分工

钢琴展开、设备 dock 和波形组件分别实现；避免共享文件并发修改，由主代理集成。构建全程 Recorder，保留失败记录；CTest、离线采样器/鼓组实际渲染与保存重开、界面布局/手势和波形异步测试分开记录。真实鼠标、键盘、声卡与听感由用户操作；无 computer-use。持续保留上轮待机、第三方插件、内存与并发图未解决问题。
