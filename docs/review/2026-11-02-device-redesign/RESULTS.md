# 工作区视觉迭代：实现与证据

状态：**源码实现及自动离线检查通过，真实桌面、鼠标、MIDI、声卡和听感待人工验证。** 参考图是布局方向，实际界面由 JUCE 控件与真实数据绘制，不把示意图音符和刻度当数据。

## 变更

- 钢琴卷帘可在主窗口扩大到工作区；`expand` / `return to arrangement` 和 Ctrl+Alt+E 切换，同一编辑器保留片段、选区和工程；展开暂隐藏编曲与侧栏，返回恢复。它不是将整个应用切到操作系统独立全屏。
- 原生采样器和鼓组显示在主窗口的底部工作区；选中轨道切换时跟随，进入原生视图暂隐藏右侧 inspector，返回恢复。既有原生装置从轨道设备列表、插件链或 inspector 的按钮都可重新打开。1280×800 保留两条紧凑轨道；1000×650 时因空间受限上方轨道区更小。
- 鼓组 pad 为 4×4，底行 MIDI 36–39；选择 pad 显示对应样本及波形。采样器可拖动起止手柄，拖动仅预览、松开按工程/revision 提交一次、Esc 取消；参数底层仍是 0..1 比例。鼓组波形仅显示，不表示 pad 已支持范围拖动或点击试听。
- 波形由单个后台 worker 对文件快照计算有界 2048 峰值，最多 16 组缓存，使用已发布采样 bank 的 SHA-256 确认内容；文件变化、排队、失败和无样本显示状态，不在 paint 或音频回调读文件。隐藏面板暂停 UI 轮询；读取慢磁盘的后台 worker 可能被阻塞，未测极限负载。
