# 原生采样器 / 鼓组人工短测

关闭旧窗口，用当前工作树 `build/monitor-isolation/bin/Release/E-musician.exe --agent` 启动。请新建测试工程，使用有权使用的短 WAV 素材；新工程含原生装置时，旧版程序不能打开，使用 Save As 避免覆盖旧工程。先调低音量。

1. 建 MIDI / instrument 轨，打开该轨 `devices`；在插件浏览器选择该轨并点 `native...`。选 `sampler`，点 `add instrument`，等待 `ready`。如果轨上已有乐器，请先另建测试轨，不会自动替换现有乐器。
2. `load sample...` 选一个 WAV，等待 `ready`；用键盘的 MIDI 60（C4）演奏，或创建 4 小节 MIDI clip、在钢琴卷帘写 60 再播放。调整 root、start/end（0..1），点击 apply、等待准备后重新演奏；确认声音和变化。
3. 另建 MIDI 轨，按相同入口添加 `drum rack / 16 pads`。选 pad 36，加载短 WAV；再给 pad 37 加另一声音。用键盘或卷帘分别触发 MIDI 36、37，检查不同声音；尝试单 pad mute、音量和 Undo/Redo。Pad 按钮是选择/编辑用途，本版不提供点击试听。
4. 用 Save As 保存新测试工程，关闭并重新打开，等各装置 ready，确认音符、样本和参数仍在并能播放，再导出 WAV 听一下。
5. 记录具体失败步骤、错误文字或长时间加载情况。不要在样本加载未提交时关闭程序；当前读取损坏/慢磁盘不可强制中断，关闭可能等待。

本版是基础采样器和鼓组：不含踏板、弯音、MPE、采样切片、时间伸缩、多个输出或复杂多层映射；重新准备样本或参数时现有发声会终止。每文件及每设备解码数据均有 64 MiB 上限；文件解码和旧/新 bank 重叠会增加峰值，尚无整体内存/延迟保证。测试仅验证独立的离线引擎，不等于真实声卡、MIDI 键盘或长期负载验收。
