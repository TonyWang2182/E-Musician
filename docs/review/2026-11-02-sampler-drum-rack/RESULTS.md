# 原生采样器与鼓组 Rack：候选验证

## 状态

首版已实现并通过离线验证；实体键盘、声卡、DPI 和人工听感待验证。不是 Live Simpler 或 Drum Rack 的完整复刻，也没有实时性能结论。[人工步骤](MANUAL-CHECK.md)。上一轮待机无声、第三方插件卡顿与按键关闭监听长音问题仍未结案。

## 范围

采样器：单 WAV，MIDI 全键盘与根音、开始/结束比例、增益和静音。鼓组：16 个槽、MIDI 36–51、每槽 WAV/增益/静音，one-shot。槽按下只选择，不提供点击试听。每个文件及每装置解码后样本均上限 64 MiB；准备过程中原始字节、解码临时缓冲与旧新 bank 可同时存在，上限不是总内存上限。固定 64 voices，超限取代最老 voice。首版无踏板、Pitch Bend、MPE、切片、时间伸缩、多输出、音色库或多层采样；参数重新准备会截断当前发声。

工程状态使用 schema 4 扩展 format `E-musician` 与版本化状态、asset ID；Save/Save As 通过 bundle 打包并核验采样快照哈希，文件发生变化时失败而不替换 manifest。此前版本不认识该装置格式，不能打开含原生装置的工程。丢失资产当前可能导致打开失败，尚未实现可继续编辑的降级。Agent 底层控制命令存在，但模型工具尚未开放这些动作。

音频回调使用固定 voices 与事件数组；准备工作由有界单 worker 完成，提交前重新验证工程/修订/装置；准备期阻止新建、打开、保存、关闭和录音。worker 正在进行的磁盘读取不能中断，故障磁盘可能拖慢关闭；每次参数变动仍重新解码全部样本、capture 整个工程，未测大工程成本。并发图回调冲突的保护仍会丢块并计数，复杂图下是否发生未验证；不能声称硬实时或生产性能已保证。
