# 0.9.1 人工短测

状态：**待人工验证**。本清单只检查本轮新增交互，不要求重做已经通过的整套录音、插件或硬件测试。真实界面与声音由用户操作；自动检查结果另见本轮 RESULTS。

启动入口：`E:/MusicAgent&DAW/Start E-musician 0.9.1 Analysis.cmd`。以最终交付时入口已生成、窗口版本显示 **0.9.1** 为准。建议在测试工程副本里操作，完成后另存一个新文件。

## 1. 语言与轨道命名（约 2 分钟）

1. 初次启动默认英文。点右上角 **Settings → Language → 简体中文**，再切回 **English**。检查工具栏、分析面板、原生装置主要控件和 Agent 侧栏都能切换；轨道名、音符与工程内容保持原样。
2. 在 Agent 输入框写一段文字，切换语言，确认草稿仍在。界面语言不强制翻译已有对话或模型回答。
3. 选中一条轨道，轨道标题处会出现 **rename / 重命名** 按钮。点击改名；再试双击轨道名称、选中轨道后按 **F2**、右键轨道标题选择重命名。四个入口应修改同一条轨道。
4. 试一个中文名称；取消一次改名，应保留原名。执行一次 Undo/Redo，名称应跟随撤销和重做。

## 2. 音源分离：结果直接加入音频轨

1. 导入一段约 10–30 秒的音乐并选中音频片段，打开 **Analyze / 分析 → Separate / 音源分离**。
2. 选择 **4 stems** 和 **Fast / 快速**，点击 **Analyze / 分析**。完成后检查下栏显示图形结果；选择一个声部，点 **Listen / 试听**、**Stop / 停止**。
3. 点 **Add tracks / 添加轨道**。编曲区应新增人声、鼓、贝斯、其他四条音频轨，与原片段的起点对齐；原音频仍在。先静音原轨，再试听分离轨，避免原音频叠加导致误判。
4. 按一次 Undo，应移除这次添加的四轨；Redo 应恢复。再使用原音频选择 **6 stems**，分析并添加，应增加人声、鼓、贝斯、钢琴、吉他、其他六轨。
5. 如需比较，针对同一短片段尝试 **Quality / 高质量**。它会多耗时；本项检查能完成及操作是否顺畅，不能以一次测试认定所有歌曲的质量提升。

通过标准：能试听、对应音频轨可见且时间对齐、一次 Undo/Redo 正常。分离串音或乐器识别不理想时，记录素材与时间段即可。

## 3. 和弦：在编曲区查看与修正

1. 选中原音频，切到 **Chords / 和弦**，选择 **Common chords / 常用和弦** 后分析，点 **Add chord track / 添加和弦轨**。
2. 编曲区上方应出现独立和弦轨，矩形区域直接显示和弦名称。横向缩放或滚动，区域应与同一时间轴对齐。
3. 关闭分析下栏，和弦轨仍应可见。双击一个和弦区域，修改标签或起止时间后点 **Apply / 应用**，轨道应立即更新；一次 Undo 可撤销这次修正。
4. 若做了多次和弦分析，切换和弦轨的来源选择，确认显示对应结果。

通过标准：和弦轨可见、与时间轴同步、可修正，关闭下栏不会把已添加和弦藏掉。常用七和弦等标签可编辑不等于任意爵士录音都能准确识别。

## 4. 分轨转 MIDI：用钢琴卷帘检查结果

1. 选择一条有音高的音频片段，例如钢琴、贝斯、人声或吉他；进入 **Audio to MIDI / 转 MIDI**。
2. 在乐器选项选择对应的 **Piano / Bass / Vocals / Guitar**，或使用 **Auto / 自动**。这是识别音域设置，不会给 MIDI 轨自动加载音色。
3. 分析完成后点 **Add MIDI track / 添加 MIDI 轨**，检查编曲区有新 MIDI 片段。双击它，应能在钢琴卷帘查看和编辑实际音符。
4. 为新 MIDI 轨加载一个可用乐器，再回放。只导入音符、还未加载乐器时无声是正常的。鼓与混合的 other 轨暂不作为这个有音高转录器的验收素材。

通过标准：对应 MIDI 轨与片段出现、音符可编辑、加载乐器后可回放；识别漏音/错音另记质量反馈。

## 5. 保存与重开

1. 将包含新轨道、修正后和弦以及改名的工程另存为一个新文件。
2. 关闭并重开 0.9.1。确认 Settings 中的语言选择保留；打开刚才的新工程，检查轨道名称、分离音频、MIDI 音符与和弦轨都还在。
3. 下栏中尚未点“添加”的候选不属于已保存工程；本项只检查已经加入工程的结果。

## 6. Agent 的相同流程（模型连接可用时）

先在 DAW 选中测试音频，并保持 Agent 的范围为 **Current selection / 当前选择**。分别试：

- “把选中音频分为人声、鼓、贝斯、钢琴、吉他和其他，先预览。”
- “识别选中音频的常用和弦，添加到和弦轨之前让我确认。”
- 选中贝斯分轨后：“把选中的贝斯转成 MIDI，保持时间位置，先给我预览。”

Agent 应先完成分析并显示待确认结果；确认后才将对应轨道加入工程。检查结果与手动入口一致，并能一次撤销。英文界面下也可以输入中文，或用英文发出相同指令。

## 反馈方式

按“语言/改名、分离、和弦、MIDI、保存重开、Agent”回复每项 **正常 / 有问题** 即可。若有问题，补充从哪一步开始、界面上的简短提示；分析效果问题可给歌曲时间段，不用抄一长串日志。
