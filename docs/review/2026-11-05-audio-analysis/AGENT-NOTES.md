## 边界审查交给主代理

1. `startJob` 允许重分析与普通文件任务共存后，历史任务淘汰不能移除仍 joinable 的任务，否则其控制线程 commit 永远不被 pump。
2. 单标签编辑和分页读取应直接操作权威 metadata，避免为和弦标签走整份 MIDI/插件数据复制。
3. MP3 prepared PCM 必须与当前原 MP3 hash 一致，不能把旧缓存的分析结果归因到后来替换的源文件。
4. 结果“曾导入”与 Undo 后的“当前存在”应区分；人工修正后的分数仍是原识别来源分数，不能宣称新标签的正确概率。

8 项分别为真实宿主/模型就绪、手动生成候选被 Agent 读取、确认后异步导入回读、重复候选幂等与一次 Undo/Redo、Agent 和弦标签修改/回读/Undo、工程保存重开、Agent 本地等待推理且仅两次模拟 LLM 请求、七类页面能力来自真实能力状态。测试没有实际调用 GPT/Kimi，没有开启物理设备播放，不是音乐准确度或长期负载结论。
