# 0.8.1 人工检查：矩形片段与原生装置

使用 `build/device-chain/bin/Release/E-musician.exe`，窗口标题应为 **0.8.1**。旧程序备份在 `.cache/pre-device-controls-20261105/E-musician.exe`；本轮新功能工程请用新版打开，使用新增形状/包络后旧版会拒绝相关装置状态。

本机另有明确指向该候选的入口 `E:/MusicAgent&DAW/Start E-musician 0.8.1.cmd`，调用既有 `Start-Agent.ps1 -DawExe` 路径。原 `Start E-musician Agent.cmd` 默认目标保持原值；检查窗口标题，避免测试到旧版。新增入口尚未用真实桌面点击验收。

先打开工程副本。以下是待人工检查的步骤，不是已完成验收的声明；自动结果见 RESULTS.md。无需重新做完整录音验收。

## 1. MIDI 与片段

- 双击 MIDI clip：音符为直角矩形，占满对应音高行；选中仍容易辨别，力度条保留。
- 编曲中的 MIDI/audio clip 占满所属轨道的片段区域，轨道之间保留细分隔线。切到紧凑行、滚动多轨后也一样。
- 缩放、拖动音符边缘改时长、框选、移动 clip、Ctrl+4 关闭吸附后移动。原来没对齐的音符不应被自动拉长或量化；短音符长度不应为“填格”被改变。

## 2. 通用旋钮

- 打开下栏 devices，顺序切换已有原生装置。旋钮下方应看得见带单位的值，可点击输入；拖动旋钮，Shift 拖动细调，双击旋钮恢复默认。
- 拖动图形时显示本地预览，松手提交一次；按 Esc 取消图形手势。一次 Undo 应恢复刚才的参数操作。声音参数在松手后应用，不是逐像素写入。
- 缩小到 1000×650，下栏打开后仍应看见一条完整紧凑轨道；1280×800 应看见至少两条。再打开 Agent 侧栏，检查数值、旋钮和按钮有没有被裁掉。装置栏右上的 `x` 可关闭下栏。切换轨道/装置时不能继承上一装置的单位、数值范围或错误目标。

## 3. 装置实际效果

| 装置 | 操作与预期 |
|---|---|
| Sampler | 加载已有 WAV；拖波形起止或调整 Start/End；拖包络或调 Attack/Release。Gate 下短按键会释放，One-shot 松键后会继续播放至样本末尾；样本长度仍限制最长声音。 |
| Drum Rack | 选中一个垫，点垫上的播放图形或双击试听。调整该垫 Attack/Release/模式/音量，其他垫数值不变。 |
| EQ Eight | 选一个频段，在形状列表切到 High pass，拖节点/频率旋钮；低频应减弱。再试 Bell / shelves / Low pass / Notch。Cut/Notch 的 Gain 应停用，因为这几种形状不使用增益。 |
| Compressor | 调 Threshold/Ratio/Attack/Release/Makeup/Mix；图上的 T/R 点可拖动，播放时 GR 显示真实压缩量。停播/旁路后不把旧值当持续实时计量。 |
| Delay | 拖回声示意的时间/反馈点，或调 Time/Feedback/Mix；听到延迟时间和重复次数变化。 |
| Reverb | 拖衰减示意或调 Decay/Damping/Mix；听尾音长短与高频衰减变化。图是参数示意，不是测得的脉冲响应。 |
| Auto Filter | 拖截止/共振点、切低/高通；打开 LFO 并调速度和深度；响应图与旋钮联动。调制图是设定示意，不是实时波形。 |

效果器的旁路和重置也走真实命令；EQ 的 Reset 重置当前频段，其余效果器重置本装置。Sampler/Rack 参数改动仍会让当前声音停止并发布新 bank；下一次按键使用新参数，当前不承诺连续无缝的自动化。

## 4. Agent 接口

选“整个工程”，加载采样后可试：

- “把这个采样器的起音改成 100 毫秒，其他参数不变。”
- “把鼓组 MIDI 36 对应的鼓垫改成 Gate，释放 200 毫秒，别动其他垫。”（MIDI 36 对应 pad 0。）
- “把这条轨的 EQ 第 1 段设为 120 Hz 高通，其他频段保持不变。”
- “把压缩器阈值降低 3 dB，混合比例设为 60%。”

先看方案中的轨道、装置、频段/鼓垫和单位，再应用；检查旋钮数值同步、Undo 能恢复。模型理解这些自然语言的准确率仍需人工检验；自动测试用模拟模型经真实 DAW 检查接口，不等同于真实模型推理验收。

本轮新增的声音参数可由 Agent 修改；整台装置的旁路仍是宿主通用命令及 UI 能力，尚未加入模型动作列表，和 EQ 单频段的 enabled 参数不同。

## 5. 保存重开

将调整后的副本另存，关闭并重开，检查 clip 位置、EQ 形状、采样包络、播放模式和声音是否一致。出现问题时记录：0.8.1、装置名、轨道名、参数、操作步骤、底部错误和是否影响声音即可。
