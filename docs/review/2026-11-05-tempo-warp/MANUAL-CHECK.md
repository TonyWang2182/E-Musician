# 0.10.0 人工短测

状态：尚未人工验收。使用本轮交付入口启动 0.10.0，先复制一个小测试工程，保留原文件。以下只测新增工作流，不要求重做全部旧硬件测试。

先保存并关闭正在运行的旧窗口，再打开 `E:/MusicAgent&DAW/Start E-musician 0.10.0 Tempo.cmd`，确认标题为 0.10.0。已准备 `E:/MusicAgent&DAW/test-projects/tempo-warp-0.10.0/synthetic-120bpm-4-4.wav`：16 秒自制测试节奏，参考 120 BPM、4/4、首拍 0.25 秒，可先用它熟悉操作，再试自己的音乐。

1. **跟随播放头**：导入一段较长音频，放大时间线，开启 Follow。播放头走到视图边缘时应滚动。手动横向滚动后显示 paused；重新播放或右键标尺 → Resume following 恢复。Settings → Editing 和时间线上方开关应一致。退出重开后开关保持。
2. **设置与语言**：Settings 的 Audio/MIDI 显示当前 M-Audio 设备/采样率/缓冲区；Configure audio devices 打开原设备选择界面。只打开通用 Settings 不应打断播放。Language 在 English/简体中文切换，轨道名和工程名保持原文；退出重开保持选择。
3. **保存**：首次保存/另存为应出现工程名与文件夹，选择测试文件夹，起一个新名字并保存。顶部先显示 Saving，再显示 Saved；悬停保存状态可看完整路径。关闭重开，轨道/插件/音符仍在。改一个片段后 Ctrl+S 应直接保存。另存为可取消；同名保存必须明确询问替换。
4. **右键**：先选中两个片段，将播放头放到其他位置；右键其中一个片段，多选与播放头不应跳动。分别试轨道头、片段、轨道空白、标尺，菜单应不同。试重复/切分/删除并 Undo；粘贴应落在右键点击位置。轨道删除后 Undo 应恢复。音频片段右键 Source and Warp 与 Analyze audio 应打开对应下栏。
5. **节拍分析**：用节奏明确的短鼓/音乐片段打开 Analyze → Beats。等待真实分析结果，观察拍线、BPM/拍号/首拍；尝试半倍/双倍与首拍修正。分别区分“让音频跟随工程”和“工程采用素材速度”，确认前工程不应变化。不要把所有歌曲的拍号/BPM 都视为已正确识别。
6. **Source/Warp**：打开同一音频的 Source，输入确认过的原始 BPM，开启 Warp + Follow tempo，Apply。等待完成后改变工程 BPM；长度、波形与声音应共同变快/变慢，音高尽量保持。手动目标 BPM 时关闭 Follow tempo。裁剪/切分后点波形定位、播放检查同一瞬间；Undo/Redo、保存重开再听一遍。首批不支持局部 Warp 标记。
7. **Agent 等价操作**：选中一段音频，输入“分析这个片段的 BPM、拍号和首拍，先让我看结果”；再要求“将这个片段按确认的原始 BPM 跟随工程速度，先预览”。涉及改全局 BPM 时明确说“整个工程采用这个素材的速度”。检查预览对象、确认、后台完成回读、一次 Undo；Agent 不应把任务接受当成完成。

反馈只需记录：在哪一步、实际看到/听到什么、是否可重复，以及测试工程名。若出现保存失败或渲染失败，保留工程并记录界面错误；不用反复点击同一个按钮。
