# 0.12 生成音乐人工短测

本页为人工步骤。自动化、真实云端推理与人工结果以 RESULTS 为准；没有填写的听感项目不表示已通过。

## 打开与手动生成

1. 保存并关闭旧程序，运行 `E:/MusicAgent&DAW/Start E-musician 0.12.0 Generate.cmd`，核对版本0.12.0。旧0.11入口保留。
2. AutoDL实例保持开机；顶部 `add... → Generate music / 生成音乐` 打开下栏。连接已配置，点击生成会通过SSH尝试启动已部署的云端服务，不会自动租卡或开通其他付费服务。
3. 在空工程输入 `Warm jazz piano trio, acoustic bass, brushed drums, relaxed groove, no vocals`，20秒，歌词留空。点击生成。可继续浏览工程；候选完成前不应出现新轨道。录音中不启动生成。
4. 看到真实波形后点击试听、停止，确认有声音；再点加入轨道。应只新增一条音频轨，原轨不被覆盖。Ctrl+Z一次撤销，Ctrl+Y恢复。
5. 另存为新测试工程，关闭重开确认音频仍在。租卡关闭或网络不可用时，已保存轨道仍应播放。含生成来源的工程为schema7，需要0.12或以后兼容版本；0.11不会打开该新格式。

## Agent

在新工程打开Agent，选择已配置的聊天模型，输入：

> 按工程当前速度生成16秒轻快的爵士钢琴三重奏，纯音乐，先让我试听，确认后再加入新轨道。

期望：不必先选一个音频片段；Agent启动真实音乐生成，候选完成后显示试听和导入方案。点击Apply/应用后才新增轨道。一次撤销移除这次导入。LLM描述音乐需求，ACE执行音频生成；助手不能凭音频元数据声称已经听过。

再试：`生成20秒中文抒情歌曲，歌词是……，完成后先给我试听。` 内容/演唱质量需要听感判断；模型能返回音频不代表咬字、风格或结构已验收。

## 失败与取消

- 生成中取消：本地不加入轨道；云端可能需要当前推理返回才能停止，界面应区分云端已取消、取消等待和未确认。不能把关闭DAW等同于停止租卡计费。
- 临时断网：正在运行的helper会有界重连同一任务，避免重复计算；超过重试上限保留E盘任务记录。不要连续重复点生成。
- 任务完成后改工程BPM，再尝试接受旧候选：应明确提示候选不适用于旧位置/速度，不偷偷改工程节奏。
- 生成期间可保存工程，但未接受候选不会写进工程；目前重启DAW不恢复未接受候选列表。原始请求与音频仍在E盘jobs目录，远端任务记录也保留。

## 数据位置

- 本地请求/候选：`E:/MusicAgent&DAW/cloud-inference/jobs/`
- 已接受、尚未另存的音频：同目录 `assets/`
- 保存后：工程旁的 `.assets`，不依赖云端文件。
- 部署/实验/备份：`cloud-inference/manifests`、`experiments`、`backups`。
- 当前生成配置：`cloud-inference/registry.json`，不是聊天API密钥。云端服务通过既有SSH密钥连接。

首批只开放ACE文字/歌词到音频，10–120秒目标时长、30–300 BPM、2/4、3/4、4/4或6/8拍号，一次一个重任务。其他拍号会在提交云端前拒绝。输出是可剪辑音频，不是分轨MIDI；目标BPM与时长不是精确对齐保证，可随后用已有节拍/Warp工具处理。YuE2、音频参考/续写、生成式补轨和其他MIR升级仍是后续批次。
