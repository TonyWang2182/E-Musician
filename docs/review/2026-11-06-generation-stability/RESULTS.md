# 0.12.1 生成默认值与分析故障隔离

状态：**实现、Release 构建和自动回归通过；真实分离与人工验收未完成**。基线 61c9384，分支 `fix/generation-stability-v0121`；不合并 main。旧 0.12.0 程序和备份保持。

## 改变了什么

- 普通生成请求沿用当前工程 BPM、拍号、播放头；未指定时长默认 20 秒，小节数由程序换算。明确风格/歌词/时长保留，咨询不被强行当成生成；候选仍需确认才导入。
- 分离在加载模型前检查系统提交内存、物理内存和已知缓冲预算。CUDA OOM 不再立即把同一模型搬到 CPU 重跑，减少内存分配失败叠加。
- 分析 Python 进程树由宿主隔离拥有，异常退出/取消/持续严重资源压力均有终态。原生崩溃夹具不再留下等用户点击的错误框，错误原因可直接在面板查看。
- 解码改为单次预分配并分块填充，分离幅度恢复不再复制完整多轨输出；失败不生成可导入结果，不修改用户片段。

本次日志能证明两次内存不足及不合理 CPU 回退，但缺少用户 75 秒六轨任务的原生堆栈，**不能声称已锁定那次 NULL 访问的唯一原因**。
