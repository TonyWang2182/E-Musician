# 0.11.0 人工短测

先保存并关闭旧窗口，再双击 `E:/MusicAgent&DAW/Start E-musician 0.11.0 Workspace.cmd`，核对标题版本 0.11.0。旧 0.10.0 入口保留。先对一个测试工程另存为新文件；本轮不要求重做已经验收的全部录音流程。

1. **Logo 与布局**：应看到树乐师启动淡入淡出，点击或按键可跳过，随后左上角为相同 Logo；资源管理器/任务栏显示新图标（Windows 可能缓存旧快捷方式图标，优先检查新 EXE）。播放、停止、录音、节拍器位于顶部。缩小/最大化和系统现用 DPI 下，按钮文字、下栏和 Agent 不应遮挡操作。
2. **轨道染色**：右键轨道标题 → Track colour / 轨道颜色，选一种颜色。轨头、片段和对应卷帘应跟随；Ctrl+Z 恢复，再 Ctrl+Y 重做。Save 后关闭、重开，颜色应保留。Reset colour 恢复默认，音符/轨道音量/声音不应改变。
3. **资源与装置**：Ctrl+F 搜索 EQ；双击将其加入选中轨，也可拖到明确轨道上。下栏最左应显示目标轨名。使用左右箭头切换装置、点击 Add 添加，拖动上缘改变下栏高度。搜索不同类别、打开项目音频时应能区分素材名和起点。标尺/滚动条上放手不应误加到当前轨。
4. **边听边调**：播放一段熟悉的音乐，拖 EQ 节点/旋钮；拖动过程中就应改变声音，松手后一次 Ctrl+Z 恢复整次调整。拖动中按 Esc 应恢复；A/B 试比，再关闭/重新打开装置。频谱随实际输入变化，停止后进入 inactive。留意爆音、断音、音量突变或旋钮回跳；这一项需要你的 M-Audio ASIO 和听感确认，离线测试不能替代。
5. **卷帘与 Agent**：双击 MIDI clip，检查矩形音符、Edit 菜单和原快捷键；展开再返回，选区应保留。打开/关闭 Agent，草稿和选择上下文应保留；小窗口会临时收起资源库。输入“把当前选中的整条轨道改为蓝色 #91A7C3，不改音符和音量”，确认选择模式是整轨，审核方案后 Apply；应显示颜色前后值，并可一次撤销。只选部分音符或时间范围时，应提示先选择整轨。

请记录失败时的版本、窗口尺寸/DPI、工程、具体控件、声卡采样率/缓冲大小及操作顺序。自动检查使用合成工程和模拟语言 Provider，没有验证任意模型都能正确理解颜色意图。A/B 只在当前装置面板生命周期内比较，未新增保存预设或所有第三方插件的无缝操作保证。
