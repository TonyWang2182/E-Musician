# 0.11.0 易乐师品牌与工作区

日期：2026-11-06（Asia/Shanghai）。状态：已实现、自动验证通过、人工待验；最终结果与冻结证据见 [RESULTS](RESULTS.md)。
基线：0.10.0 / f1658895；工作分支 feature/workspace-brand-v0110。

## 用户授权与设计依据

采用用户确认的大胡子眼镜树乐师 Logo，用于应用启动动画、Windows 应用图标和左上角。以 approved-workspace.png 为工作区构图参考，结合已确认的浅色、矩形音乐对象、细线、明确状态及连续调参标准。增加轨道染色，并沿用手动/Agent 共用命令、可撤销和工程保存语义。

图中的示例音乐、频谱、段落和 Agent 对话不作为运行数据。实际界面只显示工程内容和真实支持能力。保持 E-musician 的工程和应用身份，中文品牌使用易乐师。

## 实施与归属

1. root：资源归档、共享视觉规范、窗口 Logo/启动动画、Windows 图标、顶部控制、浏览器、可调整下栏、编曲投影和轨道颜色菜单；版本/构建脚本/总文档。
2. agent_plan_engine：轨道颜色命令、快照/存档/Undo、原生效果器连续手势事务和必要原生回归。
3. analysis_models_upgrade：效果器/采样器/鼓组控件与链条、连续调参和有界测量显示；设备侧回归。
4. agent_ui：Agent 侧栏样式与颜色工具、钢琴卷帘投影和相关 Python 检查。

本轮不操作用户桌面，不调用付费模型。已有 DEVLOG 修改和两份用户启动记录属于基线外用户活动，保留。新产物使用独立 bin-0.11.0，不覆盖 0.10.0。

## 验收

- Logo 原始 SHA 可追溯，图标资源实际嵌入；启动动画不在音频线程工作、不阻塞或伪造加载进度，后台/测试模式不显示。
- 轨道颜色：GUI 和 Agent 命令等价，严格颜色校验、回读、保存重开、Undo/Redo、旧工程缺省值；不重建音频图。
- 参数：连续操作更新实际 DSP，单次手势单次 Undo，取消和过期目标安全；实测音频仍需人工验收。
- 下栏/浏览器/Agent 开闭不丢失选择和编辑上下文，1000×650、1280×800、中英文和展开卷帘截图无遮挡；新增控件实际调用已有命令，不做假按钮。
- Release 构建、CTest、Agent/网页相关回归；原始命令及开始结束记录由 Recorder 写入 build-logs 和 docs/builds。
- 最终源码、产物和测试对应冻结版本；实际声卡/鼠标/DPI/听感与自动验证分别记录。
