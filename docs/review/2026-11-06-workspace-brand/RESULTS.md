## 性能与边界

机器 i7-13700H、14核/20线程、系统识别约 29.7 GiB 物理内存，Windows 11、MSVC Release。八段 EQ + Compressor 的纯离线基准，48 kHz / 256 样本块 / 20000块，处理106.667秒合成音频耗时0.44509秒。十万音符直接 CPU 绘制微测：平移 p95 8.904ms，拖动 p95 7.633ms。前者没有真实声卡，后者不含显示器合成/输入延迟及插件负载；都不能换算为 ASIO 全工程零爆音保证。

频谱在可见 UI 以20Hz目标读取2048点有界快照，FFT不在音频回调中；频谱为单声道平均，反相立体声可抵消，非母带测量工具。A/B 仅当前面板生命周期；Sampler/Rack 换样仍停止旧 voices。已有第三方插件慢加载、长待机问题不能从本轮回归推断对所有插件解决。
