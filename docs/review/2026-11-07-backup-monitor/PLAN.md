# 本地备份进度窗口

状态：已实现并通过自动检查及原生窗口检查；全量备份仍在下载。2026-11-07，基线 8f0dc56，沿用 maintenance/cloud-backup-20261107。结果见 [RESULTS](RESULTS.md)。

用户需要随时查看全量备份的百分比和余量，不必反复询问。已有下载继续运行；本轮不改变传输器、云端实例、DAW 或模型配置。

## 实现与边界

1. 单独的 Python 标准库进度模型读取本地 source / receipt / progress / verification JSON。区分下载、分块校验、全量校验；只有有效全量收据才显示完成。
2. Tk 原生小窗口每 2 秒更新。显示下载百分比、已下载/总量/余量、分块校验、近一分钟速度和仅供参考的剩余时间。缺失、损坏、过期进度和失败均有可见状态。关闭窗口不停止备份。
3. 不递归扫描大目录、不读取模型、不计算哈希、不访问 SSH。后台只读线程与 UI 分离；无额外服务或第三方包。
4. E 盘根和备份目录提供双击入口，同时将窗口源码复制到备份内 tools，入口不依赖开发工作树。
5. 有意义的边界单元测试、原生窗口实际渲染/持续刷新检查、启动入口与文件一致性检查。每次命令记录在 docs/builds 和 build-logs。

## 界面约定

Mode: Operate。延续 DESIGN.md 的浅纸色、细线和清晰数字；本次是明确用途的小工具，不重新设计 DAW。主要内容按下载→校验→速度/余时→存储位置排列，无装饰图或虚构进度。原生按钮支持 Tab/Enter，窗口可缩放，任务栏标题也显示百分比；可选置顶。
