# 0.13.0 最终人工验收

本轮只需集中验收此版本。自动化结果见同目录 RESULTS.md；声卡、鼠标操作和音乐听感必须由实际使用确认。

## 打开

保存并关闭旧窗口，双击 `E:/MusicAgent&DAW/Start E-musician 0.13.0 Hybrid.cmd`，确认标题是 **0.13.0**。旧版入口保留。先另存一个测试工程，不覆盖原工程。

云端实例须运行，SSH 已配置；本机登记在 `E:/MusicAgent&DAW/cloud-inference/compute-registry.json`。本地模型与云端模型不是同一算法的等价替身。明确选择模型不会偷偷换成另一个。

## 手动分析（先用 8–20 秒）

导入音频，选中片段，打开顶部 Analyze。在 Options 中先设 Start 为 0、Length 为 8 秒。选 Local / Cloud / Auto，再选模型与任务；候选生成后先看结果，再点导入。运行过程中仍可编辑，但修改原片段后旧候选应被拒绝，不能错位套用。

| 测试 | 预期 |
|---|---|
| New Light → Cloud / SCNet / Separate | 四个声部候选；试听后导入四条普通音轨，原片段保留。 |
| Keyboard → Cloud / TransKun / Audio to MIDI | 音符与模型实际返回的踏板 CC 保留。导入后给 MIDI 轨挂 Keyscape 或其他乐器，再回放。 |
| 音频 → Cloud / MuScriptor / Audio to MIDI | 根据实际结果生成乐器轨，保留通道、乐器与鼓信息；不会复制原录音的插件音色。 |
| New Light → Cloud / ChordMini / Chords | 和弦原标签可见；未知可信度不显示成满分；导入后出现在和弦轨。 |
| New Light → Cloud / SheetSage2 / Score | 可切 Notes、Chords、Beats、Sections 查看真实输出；接受后保留旋律、和弦、拍点和段落，不自动改工程速度。某个分项没有输出时显示空结果。 |
| Local / Basic Pitch 或本地分离 | 走既有本地模型；云端离线不影响本地已安装模型。 |

Auto 优先已登记的云端默认模型；每次任务重新确认服务可用。云端没有运行时会给出明确错误，可手动切 Local；不会把一个失败任务悄悄换模型重算。

## 生成与 Agent

打开 Generate，分别选 ACE-Step 1.5 XL 和 YuE2，请求 12 秒。先 Preview，再 Add track。核对实际时长；YuE2 的秒数是长度预算，可能截断，不能把它当作精确时长或自然结尾保证。

Agent 可先试：「用云端 SCNet 分离选中的这段，先让我试听」；再试「按当前工程速度，用 YuE2 生成约 12 秒暗黑 jungle」。应读取已有 BPM、拍号和范围，显示实际模型/执行位置，确认导入后才写轨。完整问句清单见 [Agent 验收](agent/MANUAL-CHECK.md)。

## 稳定性与保存

1. 云端分析时播放原工程、拖动视图、调整音量，听有无爆音或卡顿；记录声卡、采样率、缓冲区与轨道/插件数量。
2. 取消一次任务：界面应分清“本地停止等待”和“云端已确认取消”。不要把未确认当作云端已停止计费。
3. 接受结果 → Undo → Redo：每次操作完整撤销/恢复整个导入，不能重复添轨。
4. 连续保存两次，关闭重开；核对音频、MIDI、踏板、和弦、分析标记及生成来源。
5. 断开云端后再重开，已接受并保存的结果仍可播放/编辑。新 MIDI 轨仍需乐器才能发声。
6. Settings 切换中文/英文，缩窄窗口，检查模型选择、候选预览、取消及导入按钮没有被挤掉。

新 schema8 工程请用 0.13.0 打开；旧版不具备新数据结构。旧工程与旧程序已保留，回退时用旧工程副本。

新入口把 MP3 解码缓存放在 `E:/MusicAgent&DAW/audio-cache/audio-v1`，临时文件放在 E 盘；旧 C 盘缓存未移动或删除。Windows 的程序设置仍沿用原位置，工程和已接受的模型结果保存在本地项目资产中。

短暂断线会按同一任务 ID 有界重试。持续断网或退出应用后的任务不会承诺自动恢复；云端任务回执保留，可用于排查，不能把再次点击生成当作免费续传。

报告问题时只需提供：任务/模型、操作步骤、界面报错、工程是否仍能操作，以及大致时间。不要发送 API 密钥或 SSH 密码。
