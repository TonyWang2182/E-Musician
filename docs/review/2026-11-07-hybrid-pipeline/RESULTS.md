# 0.13.0 统一计算管线交付

状态：架构 2–4 已实现，七模型完整链路及 YuE2 截断元数据修订复测均通过，待用户最终人工验收。基线 a6951f3，功能分支 `feature/hybrid-pipeline-v0130`。旧 0.12.0/0.12.1 EXE 保留，main 不自动合并。

## 架构 2–4 的落地

2. **统一云端任务服务**：loopback 18082 / protocol 2，SHA 音频上传与去重、SQLite 持久任务、同 ID 幂等、单 GPU 重任务队列、独立模型进程、资源准入、取消和重连。旧 ACE 驻留服务已在空闲时迁移，不与新队列抢显存。权重、独立环境、版本清单与服务代码分开；没有重新下载模型到 E 盘。
3. **本地／云端与结果契约**：保留本地分析，新增 Auto / Local / Cloud 和明确模型。只上传请求的音频范围，下载后核对身份、大小、SHA 和音频几何；结果先成为不可变候选。转录保留 CC、程序、通道和乐器，和弦保留原文及未知置信度，综合分析保留旋律、和弦、拍点和段落。显式模型不静默替换；云端模型只开放已验证的参数。
4. **DAW 与 Agent 共用操作**：分析下栏选择模型、预览候选、明确接受；Score 四视图及 Saved score 支持保存后查看。生成可选 ACE／YuE2，沿用工程速度和拍号。Agent 能力卡、范围校验、确认卡、结果回读同步更新。接受为一次工程变更；保存后音频与音乐数据在本地，离线重开无需云端。

简要结构：界面或 Agent 发出统一命令，DAW 冻结当前工程版本和所选音频，后台帮助进程把任务交给本地模型或 SSH 后的云队列；云端按模型进入独立环境串行计算，校验后的结果回到 E 盘成为候选。用户接受后，由工程层一次性写入轨道并管理撤销、保存和重开。语言模型不直接操作音频线程，也不直接改工程文件。

## 本轮故障与修复

- 首编译：JUCE 动态索引类型歧义，显式 Identifier 修复；失败记录保留。
- 首真实任务：Windows 短暂读取进度文件导致 replace 的 WinError5；仅对本地原子发布短暂重试，不重新提交推理。
- C 盘余量约 400 MB 触发测试的磁盘保护；临时测试改到 E，新版本入口设置 E 盘 MP3 缓存和临时目录。未清理或移动用户 C 盘文件，也未降低磁盘保护门槛。
- MuScriptor：共享音频读入无条件导入 SciPy，而其固定环境不依赖 SciPy。改为只在实际重采样时导入；保留原环境/权重，真实复测通过。
- YuE2：上游截断回执是 `{abc, semantic}` 两阶段对象。转为明确 bool/null 供 GUI/Agent 使用，原分项保存在 `completion.stages`；防止达到预算却显示自然结束或未知。

失败及中间收据均保留于 build-logs/、docs/builds/ 和本档案；没有把早期失败日志改写成成功。

最终七项整链记录 `0bf7c34997`，YuE2 加强状态/Agent/保存参数断言复测 `b33b832482`，总核查 `cb271dcfb9`。验证脚本比对 356 个源码输入、原生构建/CTest输入、两份真实报告和已保存工程 SHA、旧 EXE、云服务源码清单。收尾云审计确认 active=[]、GPU used=0 MiB，实例保持运行。原生代码与 EXE 在最终两份报告期间未变化；Python 生成转换的后续修复由 7 项契约与 YuE2 实测覆盖，不据此要求无关模型重复推理。

## 使用与边界

入口 `E:/MusicAgent&DAW/Start E-musician 0.13.0 Hybrid.cmd`；VS Code 打开 `E:/MusicAgent&DAW/E-musician-Hybrid.code-workspace`。先关旧窗口，核对版本。开发使用 `python scripts/dev_compute.py configure / build / test / transport-tests / agent-tests`，每条操作单独执行。

按 [最终人工清单](MANUAL-CHECK.md) 集中验收；[Agent 测试问句](agent/MANUAL-CHECK.md)可直接复制。详细机器证据在 [VERIFICATION.json](VERIFICATION.json)，部署身份在 [DEPLOYMENT.json](DEPLOYMENT.json)。

尚未验收整曲音乐准确率、真实多乐器识别质量、主观听感、实体 ASIO/MIDI 共存，以及本轮真实 LLM 理解率。MIDI 需要配置乐器才会发声；测试保留原音频，因此非静音渲染不代表新 MIDI 音色已验。SCNet 是四声部；ChordMini 是固定 170 标签；MuScriptor 的导出力度是默认值；SheetSage2 不是五线谱刻版器。当前五个云 MIR 工程实际为 schema8，旧版不能读取新增数据。持续断网或应用重启后没有自动恢复云任务入口；有界重连和服务端回执保留已经实现。云服务空闲时释放 GPU，但不自动关闭租用实例。
