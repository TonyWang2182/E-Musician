# Agent 混合模型最终人工验收

本清单使用最终构建和已经就绪的模型服务。自动化契约/页面测试通过不等于下列人工验收已通过；请逐项记实际结果。测试另存为独立工程，不覆盖原素材。云端任务会使用租用 GPU。

## 操作前

- 选一段约 8–20 秒的真实音频，确认当前轨道、片段和时间选择。
- 打开侧栏，确认 DAW 已连接，能力列表来自宿主的实际状态。没有就绪的模型应显示不可用。
- 如需修改整个工程，把范围切到 Whole project；测试选区限制时切回 Selection。
- 给新 MIDI 轨选择乐器后再听。音符、踏板和乐器分类能保留，不代表还原原录音的插件或音色。

| 操作 / 测试问句 | 应看到的结果 |
|---|---|
| 「按当前工程的速度生成 12 秒暗黑 jungle，先让我试听。」 | 直接使用工程速度、拍号、播放头和宿主默认生成模型，不反复追问 BPM/模型。候选完成前不新增轨道。 |
| 「这次明确使用 YuE2，生成约 12 秒，先试听。」 | 使用真实 `yue2`。若模型不可用，明确报告而不暗换 ACE。实际时长、预算截断提示与回执一致。 |
| 选中一段 New Light：「用云端 SCNet 分离选中这段，先生成候选。」 | 仅选区被分析；得到四个声部候选。点击确认后添加音轨，原音频保留。 |
| 选中 Keyboard：「用云端 TransKun 把钢琴转成 MIDI。」 | 明确钢琴模型；确认卡显示真实 MIDI 轨数、音符数、控制事件数。结果提供的踏板 CC 应保留。没有输出 CC 时不声称恢复了踏板。 |
| 「用 MuScriptor 转录这段多乐器音频，保留鼓轨信息。」 | 按真实轨数和乐器元信息显示；鼓通道/音符及默认力度的限制保持真实，不把固定力度当成演奏力度测量。 |
| 「用 ChordMini 识别和弦，先让我看标签。」 | 扩展/斜杠和弦标签保持原文；未知分数不是 100% 可信度。确认后进和弦轨，可撤销。 |
| 「用 SheetSage2 综合分析这段，告诉我有哪些候选，再让我确认。」 | 分页可读音符、和弦、节拍、结构；确认卡只显示必要数量，不把候选当成已写入。接受不会自动修改工程 BPM 或拍号。 |
| 「这次只用本地 Basic Pitch 转录这段。」 | 路由明确为 Local；不会上传到云端。离线本地模型未安装时明确不可用。 |
| 「只分离选中的 8 秒」，然后在候选确认前移动原片段 | 旧候选不得套用到新位置；应提示来源/工程已变化，需要重新分析。 |
| 云端推理过程中点击取消 | DAW 保持可操作；明确区分“停止本地等待”和“已确认云端取消”。未获远端确认时不能称云端已停止。 |
| 接受候选 → Undo → Redo → 保存 → 关闭 → 断开云端 → 重开 | 接受为一次工程变更；撤销/重做完整恢复。保存的音频、MIDI、CC 和分析标记从本地打开。新 MIDI 轨需配置乐器才能发声。 |
| 把侧栏收窄至约 340 px，切换英文和中文 | 轨数、模型/位置、CC 和预算提示不横向溢出；内容可滚动，确认、输入和取消可见。 |

## 自动化真实模型验收入口

`tests/HybridComputeEndToEnd.py` 使用真实 DAW 公共命令和真实 GPU，Agent 授权/方案编译使用生产代码，但指令来自确定性测试夹具，没有调用语言模型。

通过 `scripts.dev.Recorder` 执行，传 `--exe <冻结的 0.13.0 EXE>`；可使用 `--models scnet transkun` 或逗号列表分批。`--out` 必须是新目录，默认写到 `E:/MusicAgent&DAW/cloud-inference/experiments/hybrid-native-<id>/`。

每个模型依次检查：候选不改工程、一次接受、重复接受不重复修改、单次 Undo/Redo、保存后关闭云端 registry 重开、全量音符/CC/和弦/节拍/结构比较、本地音频渲染。记录冻结 EXE 和输入 SHA、每阶段时间、状态转换、公共只读轮询耗时。少于 20 个耗时样本只给范围；足够时才给 p50/p95。这些是离线设备模式的控制往返时间，不代表物理声卡延迟、GUI 帧率或音频回调性能。

MIR 默认只分析原文件前 8 秒；生成请求 12 秒。短段成功不代表整曲精度、生成听感或音质已验收。测试保留原音频，因此非静音渲染也不证明新 MIDI 乐器音色已验收。
