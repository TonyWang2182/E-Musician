## 范围与归属

1. plugin_compat：识别BM-COZY、查崩溃证据、隔离进程复现、全安装清单扫描与有界兼容探针；PluginHost及专用测试/报告归其维护。Main入口由root协调，扫描前保留原catalog。扫描通过不保证全部音色/编辑器/运行条件都兼容；失败、跳过与人工待验分开。
2. native_dialog_style：修复24px M/S/R使用固定20px文字边距造成省略号；共享主题和紧凑布局回归，保持菜单/保存新风格。只改WorkspaceLookAndFeel、PopupStyleSmoke和必要Arrangement显示。
3. agent_english：实际模型/超时/轮次/上下文诊断，保留原生已有mix字段、批量读取装置、明确等待与错误、有效基础混音步骤；Python/web与对应测试归其维护。现有配置为GPT-5-mini/high，用户配置不改；真实模型小量验证与固定夹具分开记录。
4. root：集成、独立0.13.2构建、命令/线程边界审查、最终测试/启动入口/文档/版本管理。脚本scripts/dev_stability.py将每次命令记录到docs/builds及build-logs；DEVLOG保持追加。

## 计划与验收

- 先核对实际模型、工具和可用性，向用户解释语言Agent与专用音乐模型的分工。
- 确认并修复具体现象，再完整回归受影响路径。当前Agent在45秒左右的ProviderError及多设备6轮耗尽是诊断线索，须记录实际错误code与真实测试，不能当已确认所有失败根因。
- 插件逐进程限时检查；不输入授权数据，不修改插件安装/样本目录。主DAW内第三方插件DSP/GUI仍有宿主内执行边界，不能从扫描结论声称任意插件不崩溃。
- 混音仍为读取状态、提出方案、用户Apply、回读验证。已有瞬时峰值不当作整曲LUFS/RMS；本轮不编造自动听辨或完整智能母带能力，不把保守初始balance当专业成品。
- 检查M/S/R真实24px显示、键盘/tooltip与开关语义；原生截图、测试成功、程序启动、硬件/听感分别记录。
- 完成源码/构建审查、开发上下文和人工步骤；仅推送维护分支，不自动合并main。
