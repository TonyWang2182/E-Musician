# 0.13.4 结果与验收边界

已实现并完成自动验证；真实语言模型补验受用户正在处理的 API 额度问题阻断。没有把音乐处理、模拟 Provider、浏览器夹具或编译成功冒充真实 Agent 理解/人工听感通过。

## 软件改动

1. 中英侧栏统一指令→真实阶段活动条→简短结果/试听→Apply→Undo。完整历史、模型路线、用量与技术过程折叠；范围、截断、过期提示仍可见。等待取消确认与已取消分开，应用中不能误导为可暂停或取消。
2. 最近六项生成结果可选择；实际候选来自宿主，选择时重新核验身份、当前工程/节奏/范围/修订，之后仍显式应用。没有再次生成或语言调用；已应用结果不重复接受。列表在helper内存内，重启不恢复。新指令停止旧试听。
3. 429只允许解析最多8192字节中的精确quota类型/代码，单列insufficient_quota；不回显原始服务错误或密钥，不自动重试。
4. 从Cloud Chords切到仅支持本地的Beats会明确选Local，避免隐藏路由筛选。实时音频/DSP/云部署/工程schema未改。

架构解释：用户输入给helper，helper读取DAW当前工程和选择，语言模型只负责提出工具步骤；实际生成/分析走已注册音乐模型，输出先成为候选。界面根据helper的真实阶段显示等待，候选就绪后由用户试听或查看，再点应用；统一命令层按当前修订校验并一次提交，回读确认后显示结果，Undo还原。本轮增加的是这条工作流的简洁界面和可重选候选，不给语言模型直接写音频线程或任意文件的权限。[ADR](../../decisions/2026-11-14-agent-task-review.md)。
