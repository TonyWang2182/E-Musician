# 0.13.6 音频输入人工验收

以下步骤由用户操作；尚未验收真实 M-Audio 信号、厂商面板、听感或长期稳定性。建议先另存测试工程，停止播放和录音后再调整设备。

1. 打开 **Settings → Audio / MIDI → Configure audio devices...**（设置 → 音频／MIDI → 配置音频设备）。Driver 选择 **ASIO**，Audio device 选择实际 **M-Audio** 声卡，点击 **Apply**。输入设备显示“Uses the device above／使用上方同一设备”是同卡输入、输出共用设备；请在下方 **Input channels／输入通道** 选择物理输入。
2. 勾选 **In 1**、**In 2**，关闭 **Stereo pair 1 + 2／立体声配对 1 + 2**，点击 Apply。检查下方实际设备名称、采样率、缓冲区，以及 Active inputs／已启用输入包含两路。再只勾选 In 2 并 Apply，确认只启用第二路；恢复两路后继续。
3. 分别把信号接入声卡 In 1、In 2。新建两条音频轨，各自在 **Devices / I/O／装置／输入输出** 选择对应的单声道输入，并暂时开启待测轨的 **Monitor** 以检查实时信号。每次只给一路送信号，确认对应轨电平有反应，另一路不串入；还需核对声卡自身路由或回环设置。
4. 开启两轨 **Rec** 预备，再使用顶部全局录音按钮。停止录音后确认生成两条可独立播放的音频片段，分别单独试听。**Monitor** 仅控制实时监听，和 Rec 预备、全局录音独立；若声卡硬件直通监听已开启，按实际需要选择软件 Monitor，避免重复监听。
5. 如需把两路录成同一立体声输入：停止播放和录音，在设置中同时勾选 In 1、In 2，开启 Stereo pair 1 + 2 后 Apply，再在音频轨重新选择对应的立体声输入。确认左、右声道来自预期插孔。恢复分别录制时关闭配对、Apply，并重新选择两条单声道输入。
6. 在停止状态点击 **Driver control panel...／驱动控制面板...**，确认打开 M-Audio 自带面板。修改受支持的缓冲区或采样率并关闭，检查设置页重新显示实际值。存在未应用草稿时先 Apply 或 Refresh；驱动不提供面板时按钮不可用。播放或录音期间尝试修改应显示拒绝原因，不应改变正在使用的设备。
7. 打开旧工程，检查轨道输入。若显示“不可用”或仍是旧输入，请手动重新选择当前声卡的对应输入；不得把旧声卡的 In 1 静默换成另一声卡的 In 1。确认输入、Monitor 和 Rec 后另存工程，重开再次核对。
8. 停止后切换到另一设备：先 Apply，再确认输入通道及采样率／缓冲区来自新设备，没有沿用旧能力。切回 M-Audio 并配置所需输入，保存测试工程，正常退出并重启 0.13.6；核对实际设置、轨道输入及短录音结果。

出现异常时记录：声卡型号与驱动名、采样率、实际缓冲区、勾选通道与配对、轨道输入、Monitor／Rec／全局录音状态、错误原文和操作步骤。只出现设备名称或程序启动成功，不能替代录音及听感验收。
