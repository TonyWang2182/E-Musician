# 录音增强 V2 人工验收

新入口：`E:/MusicAgent&DAW/Start E-musician Recording v2.cmd`。先保存并关闭旧程序，再打开新版。工程先另存为测试副本；旧录音增强版仍保留。以下是待做的实体设备/听感验证，不是已通过结果。

1. **标尺**：在同一工程中用工具栏 `+`、`−` 和 Ctrl+滚轮缩放，左右滚动，分别选择 `bars`、`seconds`、`both`。小节标签应贴着对应刻度起点，概览按固定小节间隔递增；放大后依次显示小节、拍、细分。移动视口和开关 Agent 不应把第一个标签挤到别的位置，也不应无规律跳过中间小节。再打开钢琴卷帘重复检查。
2. **录音中浏览**：准备一条麦克风轨以及已挂好 VST、Sampler/Drum Rack、EQ/Compressor 的测试轨。确认输入正确，仅录音目标开启 R，开始实际录音。保持持续发声或稳定输入，依次选其他轨、打开 Devices、左右切换已有装置、打开/关闭 VST 窗口、查看原生装置与鼓垫、滚动及缩放编曲。录音波形应持续增长，目标和监听不要因选轨改变。
3. **参数与收尾**：录音时调整已挂原生效果器中允许的参数，随后停止。等待正式片段生成，回听刚才操作前后：不应有缺口、截断、爆音或重复录入。确认录音片段长度正确，能保存重开；撤销录音后应只撤销本次 take，重做恢复。参数变更与录音撤销关系按本轮自动测试结果核对。
4. **保护边界**：录音中更换声卡/输入、删除目标轨、增加或移除插件、换工程等会影响录音图或目标的操作，应明确受保护；不能表面成功后静默丢失录音。Stop/Space 必须仍可结束录音。
5. **长录音和插件差异**：在实际 M-Audio 配置下录制约 5 分钟，重复打开常用 VST。记录声卡、采样率、实际缓冲区、插件名称、轨数和出现问题的步骤。第三方窗口若短暂卡住，需要分别检查 UI 是否恢复、录音文件是否连续；不能只凭窗口响应判断音频线程状态。

补充验收预期：已松手提交的原生参数应保留；效果器拖动尚未松手就 Stop 时，预览回到已提交值。录音后的首个 Undo 只移除 take；若停止前有已提交的音量手势，再一次 Undo 才撤回该增益修改。

录音中 Arm/Monitor/输入、装置 bypass/排序、Sampler/Rack 换样本与参数、通用 VST 参数接口仍锁定；鼓垫可查看，预听仍受保护。停止后的 finishing 阶段继续锁定音乐修改，完成后恢复。上文 Space 停止指 DAW 工作区获焦；第三方窗口可能截获 Space，此时使用全局 Stop。
