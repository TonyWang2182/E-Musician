## 发现与处理

### P1（已解除）：预填 TextEditor 文本沿用深色主题插入颜色

两张钢琴卷帘截图中，鼓音高选择右侧的编号框为空白，实际源码初值是 `1`。`PianoRoll::Impl` 和通用 `ValueForm` 都在父级继承 `InstrumentLook` 之前调用 `TextEditor::setText`。固定 JUCE 版本在插入时把当前颜色保存进 text runs；随后 `lookAndFeelChanged` 只重建 caret，不重着色已存在的文本。因此后来换成白背景时，预填数字可能仍是白字。

影响包括鼓块编号，以及 Tempo / Audio Clip / WAV Export / Rename 所复用表单的初始数值。修复已在 `setText` 前明确设置 ink；后续键入也使用同一颜色。鼓块字段同时增加 `block` 标签和可访问名称。新增验收检查实际渲染字形，并排除边框和 caret 像素，不能仅凭 `getText()` 正确通过。修复后证据见下节；此处保留发现过程。
